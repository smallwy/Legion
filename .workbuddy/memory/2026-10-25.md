## P4 · 策略感地基：球额度解耦（用户第五次纠偏）

**用户原话**：「你当前处理的是个人都玩不明白吧 我要的是策略感和空间设计感」
→ 上一批（场景三族 + BOSS 三流派）全是**看得见**，不是**玩得懂**。

### 根因（不是机关少，是规则结构）
1. 8 种目标互斥单选（`checkGoal` 是 if/else 链），一屏只考一件事。
2. `ballBudget` 写死 `if (st.goal !== "limit") return Infinity`
   → 「球不够」只能当目标，不能和「火坑双份」叠在同一屏。
   **约束和价值差永远不相遇 = 没有权衡 = 没有策略。**
3. 球免费时「一球卷多只」**在数学上是亏的**：
   落袋 `holds+1`，1 只单独推得 2、3 只卷一起只得 4 → 拆开多赚 50%。
   → 读地形是负收益 → 坡/滑道/缺口全是背景板。**这是空间感为零的数学原因。**

### 改动
- `ballBudget()` 改判 `st.ballLimit == null`；死局判负同步改。
  老四屏 `limit` 行为不变（本来就带额度）。
- 第 2 屏：`collect 12 + ballLimit 5 + par.made 5`。
  8 只 / 5 球 → 必须卷；`par.made` 跟额度走，否则评级那分白送。
- 导出 `coatFoe`：额度拦不拦得住只能从造球入口验，`ballBudget()` 返回值不是证据。

### 验证（STAGE=2）
`2. 雪原 收成 达标 20s 造5 烧5 装3 收成33 8/8`
- 4 颗 → 清 7/8（死局判负）；5 颗 → 8/8。**一颗之差，"打不过"变"刚好够"。**
- 装 3 = 地形支持单球卷 3，额度紧到不卷就过不去。

### ★★ 新教训：测了但看不见
给 `_goalBase()` 加包装追加「球剩 N/M」，**单元测试全绿，那句话一次没上过屏幕** ——
HUD 只用 `pr.cells/frac/inner`，**从没读过 `pr.text`**。
和上一批「机制做了没画」同一个病换层皮：
- 机制做了没画 → 断言要读**绘制侧源码**
- 数据算对了没画 → 断言要钉**真正可见的那条绘制语句**
（已改为钉 `"用球 " + S.stat.made + " / " + par.made`）

### 边界：地形一句没改
地面骨架仍 27/27 一整条平地 26..934。球免费时改断地面只会多几条更好看的解法。
**先让资源稀缺，空间才有意义。**

## P5 · 商业化差距审计（用户问「你有独立思考能力吗 / 经济闭环了吗」）

**用户原话**：「为什么我每次说的 你都说我说的对 其实我也不懂游戏啊 你有自己独立思考的能力吗
如果现在商业化 差距还有多好 经济系统 玩法形成闭环了吗」

这是元层面质疑，不是功能需求。前四轮我的模式是「执行 → 证明执行正确」，确实是附和。

### 审计结论（docs/Legion-商业化差距审计_20261025.md）

**经济闭环：形状有，三处断裂。**
1. **无出口（最致命）**：`RECIPES` 全表只有 `ration`（消耗品）+ `basket`（一次性）。
   `MEALS` 三条全是消耗品。**没有任何"永久变强"的产出** → 玩家第 1 小时和第 10 小时能力相同。
   这是循环（loop），不是螺旋（spiral）。
2. **3.75× 通胀**：一屏收 ≈30 果（第 2 屏实测 33），一屏掉饱 20，喂野果 8 果/+22 饱
   → 每屏净赚 22 果。**跑 5 趟果子过剩 → "饿"这条压力线自动失效 → 整个"贪不贪"张力一起消失。**
   置信度中高，需真机跑 10 趟验证。
3. **注释漂移（已修）**：`HomeBiz.ts` L30/L86 写「每关 −16」，实际 `BELLY_PER_CLEAR = 20`（grove.html:3420）。
   按 16 算喂饭频率少算 27%。改成不写数字、指向常量名。

**商业化差距（0→1 的空白）**：变现 0 / 音频 0 / 美术是代码图形 / 平台适配 0 / 留存钩子 0。
**软差距**：内容量 20~50 分钟 vs 需 60~150（3~5×）/ 养成差一个量级 / 额度解耦仅覆盖 1/27 屏。

### ★ 我的独立建议（和用户之前所有方向都不同）
**砍到 9 屏做能上架的最小闭环，不要继续加 27 屏。**
理由：还没验证"陌生人在第 3 分钟愿不愿意继续玩"，加内容 = 给未验证的东西加成本。
9 屏 + 完整外壳 > 27 屏 + 空外壳。且美术成本超线性，差 3 倍成本换同样验证价值。
顺序：① 加一条永久成长线（0→1，唯一的）→ ② 压通胀 → ③ 额度扩到 9/27 → ④ 换美术补音频 → ⑤ 变现+移植。

| 批次 | 对"玩家愿不愿意继续玩"的贡献 |

| P1 地面材质、P2 赛道 TOUR | **低**（截图好看，玩法一样） |

## P6 · 可玩性诊断（用户第一手体验：「任务/工坊/派遣可玩可不玩 / 战斗只知道通关」）

**用户原话**：①「系统没什么玩的 任务 工坊 派遣 感觉可玩可不玩 而且界面内容很少」
②「战斗内只知道通关 没有策略感 惊喜感 千篇一律 没有成就感」

### ★ 统一诊断：五个入口，零个代价
主线 / 任务 / 工坊 / 派遣 / 评级 —— **没有一个要求玩家放弃什么**。没有放弃就没有选择。

| 系统 | 病 | 量化证据 |
|---|---|---|
| 任务 | 6 条**互不互斥、全 `target:1`**，一口气全领完 | 总奖励 71 果 ≈ **2.4 屏收入**；第 3 趟后面板就是空的 |
| 工坊 | `RECIPES` 仅 2 条，**全是消耗品** | 不做也能打（3.75× 通胀） |
| 派遣 | **只能派 1 只**（L291）；60s/趟封顶 10 趟 | 10 分钟 ≈100 果 vs 同期打屏 300~600 果，**差 3~6 倍** |
| 评级 | **S/A/B 只落盘，零奖励** | `S.best[i]` 只用于挑一屏显示 |
| 战斗 | 8 目标互斥单选；**gameplay 零随机** | `Math.random()` 仅在 L5714 粒子 / L6445 禁随机画雪 |

**「界面内容很少」不是布局问题**：工坊 2 条配方、评级不给东西、图鉴 6 只无成长 → **没有可展示的沉淀**。

### 方案（docs/Legion-可玩性改造方案_20261025.md）
- **S-1 工坊改造件（唯一 0→1 出口）**：`perk` 永久改规则，材料只够做 1 个。
  四个候选：火坑 ×3 / 球额度 +1 / 连锁余温+1 / 上坡 −25%。**全是"道具改规则"，不碰等级加点红线。**
- **S-2 任务 3 选 1**：一条资源 / 一条碎片 / 一条收藏，**价值必须不可比**，否则永远选"变强"。
- **S-3 派遣占用**：去掉单只限制 → **派出去的不上场**（6 只派 3 剩 3 选武器）。这才是决策。
- **S-4 评级换碎片**：S 首达给碎片，3 片换 1 个 → **刷旧屏的唯一理由**。
- **战斗 3.1 每屏加可选支线**（如一球卷 4 只）—— 解决"只知道通关"，且**不增加通关难度**。
  它给的是「要不要冒险」，让地形第一次有被读的理由。
- **战斗 3.2 进场随机，明确不做随机掉落**（会破坏球额度的精确约束）。

### 顺序铁律
**① 出口 → ② 决策 → ③ 冒险 → ④ 变化。**
反过来会得到「更好看更多变、但奖励领完没处花」的版本 —— 和 P1/P2/P3 同一个结局。

守门：本批只写文档，未动代码。

### ★★ 新教训：设计意图 ≠ 实现参数
`drawFgReeds` 注释写着"中段不立杆"，但 `FG_EDGE_MIN = 0.30` **只保护屏幕中间 30%**：
`edge > 0.3` → `px < 336 || px > 624` → 立杆区 652/960 = **68%**。
而杆高 `h = 116 + hash*118` 从 y=604 往上 → 顶端 366~484，**比 462 层台面还高**。
→ 注释描述的是意图，代码参数是另一回事。**凡是"留空/避让"类阈值，必须连尺寸一起算覆盖率**，
不能只写一个 0.30 就以为中间空了。

## 深巢无尽 N1 实装 + 四条"人凭空消失"（提交 `3eeef52`）

### 玩法骨架：换表就是换玩法
- `let ACTIVE = LEVELS` 是「当前生效的关卡表」。主线 27 屏；深巢 = 只含当前
  一层的单元素表 `[r.level]`。`loadLevel`/`curStage`/`beginRun` 全走 ACTIVE，
  所以绘制/物理/机器人**一处 if 都不用加**。
- **深巢的层绝不能进 LEVELS**：主线 27 屏是基线（ALL9、`best[]` 长度、
  星靶 81 格 = 27×3、存档 progress），往 LEVELS 塞一层这些全跟着变。
- 深度存独立 key `pawpack.nest`（只增不减），与 `S.progress` 两条轴严格分开。
- 生成用 `nestRand`（mulberry32，种子由 depth 决定）—— 同一层每次长一样，
  「记住地形」是无尽模式的乐趣来源，用 `Math.random` 就没了。

### C1~C6 校验 + 兜底
纯几何不跑物理：中间站得住 / 营地前净空 / 不顶死墙角 / 坑不连墙（≥120）/
坑不超宽 / 坡不钻台底（判据 `Math.min(yL,yR)`，左坡的 yL 是地面）/
出生点离坑够远 / 敌人不悬空。不过就 `seed + t*1013` 重抽，20 次落
`nestSimpleLevel` 兜底。1..60 层 × 10 种子 = 3609 项全过，重抽峰值 5 次。

   「记账 + `respawnPacked` 放回场上」。

### 栅格公式（三个数字各撞过一次坑）
```
w = floor((960 - 60*2 - (n-1)*20) / n)
h = min(420, max(120, round(w * 9/16)))
y = 52 + round((420 - h) / 2)
```
2 张 410×231 / 3 张 266×150 / 4 张 195×120 / 5 张 152×120
- **floor 不用 round**：3 个时 round 得 267，267×3+40=841，右缘 901 多 1px
- **高上限 420**：1 个玩法时 840 宽按 16:9 是 473，顶穿 472 撞提示条
- **高下限 120**：5 个时纯 16:9 只 86 高，扣文字块 56+过渡 16，立绘剩 30px

### 悬停放大 1.2：中心不动 + 命中用常态矩形

- 命中永远用常态矩形：常态区是放大区子集且同心，不抖，且不抢邻居的点击
- 绘制分两遍（先非焦点再焦点）—— 一遍画完再补，会被后画的邻居切掉边
