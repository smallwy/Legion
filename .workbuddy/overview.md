# 主界面：任务挂牌改椭圆，与名字板同族

## 做了什么

用户在原图上圈了路标的「任务」，要求"任务也要处理起来椭圆"。这是同一处的第三次收口：

| 轮次 | 做法 | 问题 |
|---|---|---|
| v1 | 72×36 橙色胶囊浮在牌子右边 | 不在牌上，还压在「去苔原」圆徽的位置 |
| v2 | 去掉底板，字直接写在木牌上 | 解决了"浮在旁边"，但与另外四块牌子不是一套形状语言 |
| **v3** | **54×26 椭圆胶囊钉在木牌正面** | — |

## 关键决策与依据

**尺寸 54×26 不是"重要就做大"，是载体决定的。**
名字板是 52×24 / 12px 字。任务胶囊 +2 宽 / +2 高 / 字 +1px —— 因为路标那块木牌在背景图里
只有 60×38 的可视面积，是全场最小的物件，同尺寸远看会塌成一个米色点。圆头取 13 = 高的一半，
与名字板同一种端头形状。

**字号 15 → 13、字色统一到 `#6B4025`。**
这两个数不是重新挑的，是跟着名字板抄的：名字板 24 高配 12px（字占 50%），26 高按同比例该配 13px。
v2 的 15px 是"字是主体"时定的 —— 有了底板之后，26 高减两侧 3px 描边只剩 20px 内区，
15px 只剩 2.5px 边距，读作"字撑满了胶囊"。

**按钮 x 从 −419 收到 −425。**
旧的"净区 190..252"把木牌左侧的厚度斜面也算进了可放字区。真牌面是 175..254，中心 214.5。
两个字时看不出偏，54 宽底板一上去就是"牌没钉正"。改完实测左右留白 13 / 13.5。

## 修掉的两个真 bug

**1. 按下反馈在真机上等于没有。**
原来在按钮上叠一层暖光 Graphics。但 Graphics 是按钮自己的组件，渲染顺序在**子节点之前**，
而不透明底板是它的子 Sprite —— 暖光被整块盖住。离屏渲染图上看得出变化，真机看不到。
改成给底板 `Sprite.color` 做 tint `(255,226,168)`，不占层级，也不会被自己盖住。

**2. 工作区的场景文件带着一批不是自己写的改动。**
`git status` 里 `Home.scene` 是 M，但 `_orthoHeight` 从 360 变成 468.06 —— 相机被改过，
按这个值渲染整屏 UI 都会错位。查进程发现 `CocosCreator.exe` 在后台跑着，编辑器回写过文件。
做法：先 `git checkout --` 回已确认版本再加节点，最终 diff 是 **112 增 / 0 删的纯增量**。
