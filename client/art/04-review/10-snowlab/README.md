# snowlab 评审图

`client/prototype/snowlab.html`（推雪成球的雪山挖箱原型）的目检留档。
**图都能重跑出来**，这里的副本是为了"当时判断长什么样"有据可查：

```
node client/tools/_snowlab-shot.js        # 落点 client/shots/（已 gitignore）
```

看这些图之前要知道两件事：

1. **逻辑绿不代表画面对。** 断言只守数值和通路，遮挡、浮空、颜色糊在一起
   只有出图能看出来 —— 这个目录里的每一张都对应一次"断言全绿但图不对"的返工。
2. **图是编译器/渲染器跑出来的，不是手绘。** 改完 `.html` 必须重跑，
   否则看的是上一版。
