# snowlab 第 11 批：敌人重做 / 黑洞 / 打击感（2026-10-28）

用户这一轮的四条：

> 1 有个问题啊 敌方为什么用我方的宠物呢
> 2 你这战斗背景是立体的吗 有一些和战斗无关的凸显出来 UI设计是不是不合理

>   比如打箱子破碎感 球的击碎感 有物理打击的感觉
> 3 黑洞是怎么回事 太突兀了点 你可以地下做个玄关地方出来

## 01 三种敌人侧视与投掷物

敌方从 `bunny / doggy / hoggy`（兔、狗、刺猬）换成 `moss / fang / grub`
（苔泥团、尖牙兽、霜甲虫）。**这三种本体块关系不同**：一团 / 横着拉长 /
拱起的硬壳 —— 缩到 34px 也不会混。

侧视是这一张要证明的事：单只主眼、口鼻朝前、腿一前一后。

投掷物跟着品种走：泥球（圆、带凸起）/ 牙（弯锥）/ 冰锥（3:1 的六面体）。

## 02 球撞碎箱子

打箱子那一下要"像被撞碎的"，三件套：

1. **碎片有材质形状** —— 木箱碎成会转的板条，石箱碎成棱角块；
   全是方点的话，木和石碎得一样，玩家读不出"这是什么做的"；
2. **顿帧跟着动量走** —— 特大球 0.11s，小球 0.06s；
3. **两层冲击环** —— 深棕打底 + 浅色压上（只用浅色在雪地上等于隐形）。

环同时最多 4 个：特大球会连碾 4~5 个箱子，十来个环叠起来就是一团结。

## 03 黑洞改成地穴

原来它悬在箱堆顶上（生成侧取的是 `colTop`，那一列有两格箱子它就浮空），
画法又是个规整椭圆 + 顶部高光弧 —— 合起来就是"墙上贴了一只紫色的眼睛"。

现在：贴地（`y = floorY`，生成时**换一列**而不是删箱子，删箱子会打断井梯）、
破口是不规则路径、往下收成漏斗挖穿楼板、洞内三级石阶、两侧被顶开的断板、
口沿撒碎石。紫光从洞里往外透，只照亮口沿四周，不照亮内壁。

## 04 箱子堆中的陶罐与敌人

罐子/小箱从装饰层搬进 `boxes`：**看着能撞的，就真能撞。**
以前它们能被人穿过去，这一层场景就没了可信度。

## 05 地表层

地表只放"撞不撞无所谓"的东西（蘑菇 / 树桩 / 碎石 / 路牌）。
容器类全部实体化，所以量变少了，但每一件都成立。
