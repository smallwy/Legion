# 13 · 角色尺度与画面质感（2026-10-28）

用户这轮的要求是「立绘精致」「战斗空间合理」「你要发挥自主性去处理」。

## 一句话结论

**"立绘精致"和"战斗空间合理"卡在同一个前提上：尺寸。**
角色原来只占屏高 7%（600 高里 42），比木箱（48）还矮 —— 细节全被像素吃掉，
再怎么画都是"小矮人站在一堆大箱子里"。先把尺度提到 1.5 倍，再谈精致。

## 改了什么

| | 改前 | 改后 |
|---|---|---|
| 玩家碰撞框 | 30×42 | **45×63** |
| 敌人碰撞框 | 34×30 | **51×45** |
| 角色占屏高 | 7.0% | **10.5%**（形象 12%） |
| 主角绘制 | 两块纯色 + 粗描边，没有腿 | 四档色阶、径向渐变、肚皮亮面、鼻+ω嘴、虹膜双高光、呆毛、两条腿 |
| 敌人绘制 | 纯色块 | 渐变 + 顶光 + 底部接触阴影（三种各按体块走） |
| 箱子 | 平涂 + 点缀 | 统一左上→右下斜向明暗（一笔管住木/石/铁/金/冰） |
| 影子 | 画在脚底（跳起来跟着飞） | `groundAt` 找地面，离地越远越小越淡 |

**形象和碰撞框必须同比例放大。** 只放大形象 = "看着能挤过去、其实过不去"，
踩在箱沿上会莫名掉下去 —— 那正是用户说的"空间不合理"。这条已经写成断言
（第三十节，判据 `30 × ART_K === PLAYER_W`）。

## 踩过的坑

1. **只放大形象不动碰撞框**（第一版）→ 玩家被箱子顶住、走不动。
   探针量到 vx 在 0 和 -260 之间抖，看着像"推球坏了"，其实是路被堵了。
2. **腿藏在身体里**：腿顶 `by-5.2`、身体底 `by-2.5`，只有 2.7px 露头，
   被描边一压就没了 —— 画面上是个圆球"坐"在地上。身体上移两格才露出来。
3. **鼻嘴又加了一次 `face` 偏移**：`ex` 本身就是朝向偏移，再加 `face*3`
   让整张脸歪 3px，ω 嘴正好压在右眼下面（放大图里那个"糊在眼睛下的红块"）。
4. **ω 嘴不能用两条 `arc`**：半圆的起止点接不上，画成一个问号。
   要从中心出发的两条二次曲线。
5. **腮红溢出轮廓**：中心 ±13.5、半径 3.4，外沿到 16.9，头半径才 15。
   必须 clip 在头圆里，否则每边挂一小块红，放大后比腮红本身还显眼。
6. **对比出图不能只出新的**：`_cmp-shot.js` 拼上下两张，旧图用
   `git stash` 后跑同一个工具生成 —— 同一场景、同一种子才有可比性。

## 还没做的

- **真·AI 立绘**。现在这版是"程序化厚涂化"，把纯色块补成了有体积的矢量画，
  但还不是画师/模型出的成品图。**这次把天花板抬到了 63px**，同样的立绘
  在 63px 下比在 42px 下能多保住一倍细节 —— 这才是接 AI 素材的前提。
- **手臂**。主角目前只有腿，没有手。Q 版可以不画，但发射/推球时缺一个动作。
- **关卡空间没有等比放大**。角色宽了 50%，但洞宽（96~192）、层高（240）、
  箱格（48）都没动。断言验证过最紧的三处（井梯 7px、洞口余 25、走廊门槛）
  都还有余量，所以这次没动它们 —— 动就要重排整张关卡，风险不成比例。
