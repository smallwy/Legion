## 这一轮改了什么

### 尺寸：三样东西三个尺度，不再共用一个系数

上一轮我把 `ART_K = 1.5` 一刀切套到玩家和敌人身上，结果三样挤在同一档：
玩家 45、敌人 51、箱子 48。层次塌了，敌人读起来像"和箱子同级的障碍物"。

现在拆成三个独立问题：

| | 尺寸 | 关系 |
|---|---|---|
| 箱子 | 48 | 地形单位，关卡按 48 一格生成，**永远不动** |
| 玩家 | 45×63 | 比箱子**窄**、比箱子**高** |
| 敌人 | 37×33 | **必须明显小于箱子**（0.77） |

判据进断言第三十节：`FOE_W / 48 <= 0.85`。用 0.85 不用 1.0 ——
"小于"不够，要"明显小于"，0.95 那种擦边在屏幕上读不出差别。

### 动法：从体态推出来，不是拍脑袋

| 敌人 | 体态 | 动法 |
|---|---|---|
| 苔藓团 moss | 无腿团块 | `slide` 贴地滑，`jump: 0` |
| 尖牙兽 fang | 四足 | `run` 跑 + 跳，`jump: 545` |
| 霜甲虫 grub | 多足宽扁甲壳 | `crawl` 贴地爬，`jump: 0`，20px 以内的坎直接蹭上去 |

`jump: 0` 是"这条腿不会跳"的物理含义：物理层见到它就不起跳。

顺带删掉了一个**纯视觉的持续弹动**：原来 `breathe = 1 + sin(t*4.4)*0.04`
挂在身体椭圆的纵向半径上，每只怪都在原地一胀一缩、永远不停。
那是人的呼吸，虫子没有横膈膜；37px 上读起来不是"活着"，是"在弹"。

### 上色：一个 colorStop 都不留

`foeGrad`（径向渐变三停靠点）+ `foeVolume`（柔光顶亮 + 半透明接触阴影）
整体换成 `foeCel`：

```
clip 到轮廓 → 铺满暗色 → 偏移到左上的基色椭圆盖上去 → 剩下的就是硬边暗面
```

没有渐变，边界天生是硬的。偏移量就是暗面宽度（现 0.20/0.45）。

同一个函数给主角用（传 `{lit, body, shade}`）。敌人和主角从此是同一套上色语言。

## 踩过的四个坑

1. **暗面方向不能一刀切。** 第一版压右下，尖牙兽的暗面正好被自己的头挡住，
   身体还是平的。趴着的东西最暗的是**下沿**，改成 0.20/0.45。
2. **暗面宽度不能太小。** 0.17/0.21 只留 2~3px，读起来是"平涂加一条细边"。
3. **不要加独立高光块。** 0.44×0.33 是一枚椭圆贴片；缩到 0.24×0.17
   变成"背上长了块斑"，比贴片更像画错。这个尺寸上**根本不该有高光**，
   Q 版塑体积靠"暗面从哪开始"，不靠"亮点在哪"。
4. **肚皮色块会盖掉暗面。** 肚皮几乎贴到身体下沿时（离 1px），
   正好把 cel 下半圈暗面全盖住，身体又变平。肚皮下沿要比身体下沿高一个暗面宽度。

## 顺带修的两处「乱」

- **出生点会叠加**：原生成器里 `if (!pool.length) pool = all.slice()` 会整池重来，
  等于允许两只怪落在同一位置 —— 出图上是"蓝色甲虫压着一团绿色苔藓"。
  现在两档间距（96 / 56），都不够就挑**离已有怪最远**的位置。
- **敌人会互相穿过去**：出生隔 96px，跑几秒就重叠（苔藓 84px/s）。加了最轻的分离力。
  推力必须**明显大于走速**：第一版 1.6px/帧 对上 1.67px/帧 的走速正好抵消，
  两只贴着一路顶着走。

## 还没做的

- **"乱"没解决。** 这张图上每层都塞着蘑菇、路牌、管子、桶、坛子、旗子、蛛网，
  加上一屏能看到 2.5 层，噪声密度远超角色本身。这一轮只清掉了"敌人重叠"这一块。
  真要治需要单独一轮：降装饰密度 + 给可攀爬路径做视觉强调。
- **主角被箱子夹住**（06 图左侧）：出生点在人缝里，两边都是箱子。
  这是"战斗空间"的问题，不是画风的问题。
- 主角头上还有几笔黑色线条（耳朵描边）在放大后显得杂，需要单独打磨。
