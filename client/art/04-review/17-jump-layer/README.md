# 17 · 上下层：二段跳 + 洞口翻越 + 井口断口

用户这一轮的原话（2026-10-28 第二轮）：

> 你继续做　1注意处理的太直了吧　太陡　2宠物需要轻松的上下层跳动

## 1 · 先摆清楚原来卡在哪

层高 **240**、板厚 26、净空 214，玩家 **63** 高、单跳 **123**。

```
下层地面 ──240── 上层地面        单跳只到 117，永远差 123
井梯箱柱 144（3 格）              比单跳高 21 —— 从地面爬不上去
```

所以上行只有一条路：**踩到井梯顶、按 W、瞬移**（`wellClimb`）。
用户说的"太直、太陡"和"不轻松"，是同一件事的两面：**通道是一根直上直下的
箱柱，上去靠瞬移**。

## 2 · 改了什么

| # | 改动 | 位置 |
|---|---|---|
| ① | **二段跳**（空中还能再跳一次，`NUM.hero.airJump = 1`） | `stepPlayer` |
| ② | **地面按 W 就是跳**，只有站在井梯顶（`d ≤ 160`）才是爬 | `stepPlayer` |
| ③ | **洞口翻越**：上升中脚下穿过某层楼板面时，自动横移到洞口外那侧站住 | `stepPlayer` 末尾 |
| ④ | **楼板断口全层走茬口**（原来只有地表层用，地下是一刀切的直角） | `drawPlat` |

②③ 是配套的：二段跳能把脚送过楼板面，但人会停在洞口正上方、一松手又掉回去
——**"跳上去了"和"站得住"是两件事**。③ 补的就是这半步。

## 3 · 为什么二段跳不会毁掉"箱子是路"

这是这一轮唯一需要算术的地方：

```
层内天花板压着：净空 214 − 人高 63 = 脚最多到 151
3 格箱山 = 144 < 151  ← 危险，只差 7
```

实测（`_snowlab-check.js` 三十节）玩家仍然跳不上 3 格箱顶，因为
起跳点几乎从不贴着天花板，二段跳的第二段会被楼板吃掉大半。
**箱山的攀爬路线没有被绕过。**

而洞口正上方是空的，所以二段跳在那里能走满 246 > 240 —— 这是"只在洞口里
生效的跳跃"，**不需要对井做任何特判，几何自己就分开了**。

## 4 · 验证到了什么 / 没验证到什么

| 手段 | 结果 |
|---|---|
| `_snowlab-check.js` | **183 项全绿**（含"井梯顶按 W 回上层" 26/26、"纯跳 + 扒边" 21/21） |
| `_layer-up.js` 静态可达性 | 120 个种子 / 390 个洞口：**100%** 可达（基线 99.2%） |
| `_layer-up.js` 真跑 | **没跑出可用数字**（见下） |

**没跑出来的那条，写清楚**：`_layer-up.js` 第二部分想把"从井底按两下 W"
做成可复现的量化，量到 12~38% —— 但失败的样本全是"根本没起跳"
（`p.jumpHeld` 一直是 false），说明是**探针注入按键的方式不对**，
不是玩法的问题。`_snowlab-check.js` 里同样按 W 的两节是 26/26 和 21/21。
**这条数字不可信，别引用。** 手感只能人在浏览器里试。
