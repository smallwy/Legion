# 18 · 踩球（站在雪球上）

2026-10-28 第三轮。用户原话：「没办法站在球上」。

## 结论

不是 bug，是**从来没做过**：`solids()` 只返回平台和箱子，球不在碰撞世界里 ——
球顶对玩家来说是一层空气，人直接穿过去落地。

补上之后：踩球顶能站稳、能借高起跳（实测从球顶起跳上升约 107px）。

## 顺带修掉的两个抖动 / 瞬移

1. **静止的球会自己抖 6.2px**（以 5 帧为周期）。
   撞箱判据写的是 `球底 > 箱顶 + 6`，球贴住箱顶时这个条件不成立 →
   这一帧不算落地 → 球继续掉 0.58px，掉满 6px 才被接住。
   人踩上去整个人跟着抖。把 6px 去掉（"从上方来"已由 `prevBottom` 判定）。
2. **跳起来被整段横移一个身位**（44px），这就是用户说的「跳起来一起往后走」。
   是 `stepBody` 的扒边：把人从台子外侧挪到台面上，一帧完成，而且**不看方向** ——
   往右跑跳时人可以被挪到左边。现在加了「不往运动反方向扒」+「一帧最多 20px」。
