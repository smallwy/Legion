# 20 · 楼板半透 / 落球砸箱 / 箱顶推球（2026-10-28 第四轮）

## 一句话

用户三条原话，对应三处机制改动：

| 用户原话 | 改了什么 | 断言 |
|---|---|---|
| 「这个横梁我方是可以跳上去的　也可以下来　只要没箱子　不需要在空档里才能跳」 | 楼板变成**半透层**：只挡落下、不挡上跳（`stepBody` 里一条 skip）；站板上按 S 穿下去（`p.dropT`）；二段跳从 720 提到 `airJumpV = 790`，两跳合计 272 > 层高 240 | `_snowlab-floor.js` 一、6 项 |
| 「球掉下去 是可以杂碎箱子」 | `stepBalls` 里"落到箱顶"分成**砸**和**滚**两件事：落地那一帧 `vy ≥ crushVy(320)` 就碎，碎完 `vy *= keepSpeed` 继续往下犁 | `_snowlab-floor.js` 二、5 项 |
| 「这种1级平面 球很难撞击到　最好想想机制上去规避」 | `pushBalls` 从"包围盒相交"改成"圆心距 + 12px 余量"；慢球不再 `continue` 穿进箱体，改为贴面停住 | `_snowlab-floor.js` 三、5 项 |

## 踩过的两个坑（写在这里，因为都是"断言写错"而不是"代码写错"）

1. **"被挡住"和"根本没跳"在最终位置上长得一模一样。**
   第一版判据看的是 60 帧后脚底的高度，人撞了箱底就落回原地 ——
   于是 7 个样本里 4 个被记成"没挡住"。改成量**整段过程的最高脚底**。

2. **试验场只铺了一口箱子。** 玩家 45 宽、箱子 48 宽，人放在窗口左边 7px 处，
   右边溢出箱沿 4px，就顺着箱侧擦上去站到了楼上地板 —— 图上看起来像
   "楼板还是能穿"，其实是试验场没铺满。改成两口箱子铺满 96px。

## 没有改的

- 箱子的碰撞：楼板上摞着箱子的那一格跳不上去，判据就是箱子本身（撞箱底，
  脚停 `楼板顶 + 63`），没有为它单写一条规则。
- 怪的碰撞：楼板只对玩家半透。怪一旦也能穿，会跳进上一层回不来
  （它们的巡逻走廊是按本层量的）。
