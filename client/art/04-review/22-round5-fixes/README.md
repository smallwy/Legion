## 斜坡改了什么（细节写在 `drawRamp` 的注释里）

碰撞面**没动**（`surfY()` 还是线性，能不能走上去、球会不会顺着滚都建在它上面），
改的全是画出来的那条边：

1. **顶边起伏**：三个不通约的正弦叠加，幅度 ≤2.6px，**只往高的一侧偏**
   （脚陷进去 2px 看不出来，浮空 2px 一眼就是"没站住"）。两端收敛到 0，
   坡脚要和地面平接。
2. **坡沿压石头**：两块半露 5~7px 的石头**画在墨线之后** ——
   起伏只是让线变软，真正把"一条笔直的边"打断的是让它局部消失。
3. **断面往里塌**：原来是一面 90° 直墙（土挖开之后不可能这么直），
   改成侵蚀剖面：顶上收进去、中段最深 12px、坡脚反而往外鼓一点。
   斜坡横向不挡（`stepBody`），这面墙本来就是纯画的，改它物理零影响。
4. **坡脚摊开**：三层套着的小土丘，不是半圆扣在地上。
5. **铺装不再等分**：板宽用"权重归一化"分配（0.5~1.5 倍），
   且改成**一条连续的板带 + 竖缝**——原来每块板各抖 13~18px 厚度，
   板缝里露出整块土，放大看是一排"悬空的横条"。

## 另外两条

- **断梯删除**：`FLOOR_KINDS` 里去掉 `ladder`，放置约束和绘制分支一起删。
  场地里本来就有能爬的井梯（那摞 3 格箱子），一个能用一个不能用 =
  在教玩家"别信画面"。`_snowlab-check.js` 反过来守"它不许回来"。
- **碎箱不再放冲击环**：环从箱子中心放出去，而球正贴着箱子滚，
  环心几乎就是球心 → 读成"球外面套了一圈波纹"。碎箱的力已经有碎片、
  震屏、顿帧三处在讲。
- **墙角挤球**：`pushBlocked` 现在返回 `'wall'` / `'box'`，墙挡不再是
  "什么都不做"，而是给 0.45 倍反向速度 + 一点上抛，把球从墙角挤回场内。

```
NODE_PATH=<workspace>/node_modules BEFORE=/tmp/snowlab-before.html MODE=ladder node client/tools/_fixshot.js
NODE_PATH=<workspace>/node_modules BEFORE=/tmp/snowlab-before.html MODE=wall   node client/tools/_fixshot.js
```
