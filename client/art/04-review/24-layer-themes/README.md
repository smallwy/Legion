# 第七轮反馈：层与层之间没有差异化

用户原话：「感觉层与层之间没有差异化啊」

---

## 问题在哪

改前的四个"房间主题"（木屋 / 砖房 / 石洞 / 地窖）**确实存在，也确实在换墙的纹理**，
但整套配色压在同一支米黄里：

| | 墙 bg1 | 明度 | 色相 |
|---|---|---|---|
| 木屋 | `#F9E0B8` | 高 | 黄 |
| 砖房 | `#F7D2C8` | 高 | 粉 |
| 石洞 | `#E4DACC` | 高 | 灰黄 |
| 地窖 | `#DED2E8` | 高 | 淡紫 |

明度差不到 8%、色相差不到 20° —— 缩到一半就是同一张壁纸换了个色温（见图 02）。
**更致命的是另外三块面积更大的东西完全没变**：

1. **楼板**（每层出现两次：自己的地板 + 下一层看到的天花板）—— 写死三段暖土色；
2. **平台顶面** —— 写死三段奶油黄，而它比楼板本身还显眼（玩家站在上面，
   26px 厚的楼板里顶面占 9px，而且是全屏最连续的一条横带）；
3. **光色** —— 吊灯 / 枝形吊灯 / 灯笼三种光源全是同一支暖黄。

再加上**道具池四层共用一份**、**天花板是一条平边**，四层就真的只是"下了一层"。

---

## 改了什么

### ① 色阶：明度递减 + 色相跳冷

| 层 | 墙 | 明度 | 色相 | 光色 |
|---|---|---|---|---|
| 木屋 | `#FAE2B8 → #E7C392` | 1.00 | 暖黄 | 255,232,170 |
| 砖房 | `#EFBB9A → #D4947A` | 0.93 | 赤陶红 | 255,204,138 |
| 石洞 | `#CDD6DB → #A7B5BD` | 0.82 | **冷青** | 176,214,255 |
| 地窖 | `#B4A9CC → #8B7FAA` | 0.70 | 暗紫 | 206,178,255 |

**第三层跳冷色是关键的一步。** 前两层再怎么调都在暖色里打转，一跳冷，
前两层的暖才被读成"两层"。压暗/反光的颜色也按层取（`dark` / `lite`）——
暖棕压在青灰上会发脏绿，一脏整层就"没画完"。

### ② 楼板换材质（`slabFill` / `slabSeams` / `snowCap`）

| 层 | 板体 | 细节 | 顶面 |
|---|---|---|---|
| 木屋 | 暖棕木 | 板缝 + 节疤 + 苔 | `#F1D3A4` |
| 砖房 | 赤陶 | **错缝小砖**（砖高 13 / 宽 34） | `#D9B49A` |
| 石洞 | 冷灰岩 | 不规则断层 + 碎石 | `#CFD5DA` |
| 地窖 | 铁板 | 横接缝 + **两排铆钉** | `#A79FB8` |

顶面（`snowCap`）以前是写死的暖木三段 —— 于是紫色地窖的地板还是黄的，
底下板体换得再狠也看不出来。这一条是出图之后才发现的，`_slab-probe.js`
采样像素才钉死：`顶 160,138,102 / 130,112,103 / 99,106,112 / 64,64,76`。

### ③ 天花板剪影（`drawRoomSig`）

为什么挂天花板：楼板底面横贯整幅，而玩家脚下的东西全被箱子和敌人挡着，
**头顶那条边永远是空的**。四套形状语言刻意不共用：

- 木屋 → **桁架**（横梁 + 两根斜撑 + 中柱，围出一个闭合梯形）
- 砖房 → **横贯整幅的管道 + 法兰**（接上两边侧墙）
- 石洞 → **钟乳石**（长短悬殊 3 倍、间距 90~170 不等）
- 地窖 → **三道拱肋**（起拱点在墙上、拱心顶到天花板）+ 吊链圆环

### ④ 光色跟层（`drawDecoBody`）

冷色房间里点一盏暖黄灯，那点暖才读得出是"唯一的火源"。

## 两次返工（都在出图上才看出来）

| 第一版 | 出图上读作 | 改成 |
|---|---|---|
| 木屋两根墨线斜撑 | 墙上两道划痕 | 闭合梯形桁架（横梁用木头色 + 墨线） |

| 地窖下弓细弧 | 一根挂着的电缆 | 反过来：起拱点在墙上、拱心顶到天花板；细弧改成有厚度的带状肋 |
