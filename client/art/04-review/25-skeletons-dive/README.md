# 第八轮：骨架差异 + 深潜模式

用户原话（三句连着来）：

1. 「没必要都是多层 可以循序渐进 你现在能把关卡设计深度规划出来吗」
2. 「主线玩法30关也不够吧」
3. 「那你继续 然后做深潜」

规划落在 `docs/CR-031_snowlab_关卡深度曲线规划.md`（v1→v3），
这一轮是把其中**「骨架」和「深潜」两件**真正写进 `snowlab.html`。

---

## 一、骨架：只改洞的 x

**零新美术。** 六种骨架全部由「每层洞开在哪几列」决定，一行贴图都没加。

| 骨架 | 洞 x | dx | 读起来是 |
|---|---|---|---|
| 直井 | 240 / 432 | 192 | 两列小幅交替，一路往下 |
| 之字 | 96 / 720 | 624 | 每层横穿整屏 |
| 中枢 | 336 / 624 | 288 | 洞贴中线，四周全是箱山 |
| 靠壁 | 528 / 720 | 192 | 洞全挤在半屏之内 |
| 螺旋 | 96 / 336 / 576 | 240 | 左→中→右→中，四段一轮 |
| 双井 | 144 / 336 / 672 | 192 | 每层两个镜像口 |

发牌：主线按 `stage` 固定轮转（`(stage-1) % 6`，任意连续 6 关不重复），
深潜按种子随机（种子过 `mix32`，见下面"踩坑 ⑤"）。

### 骨架能被感知，靠的是「每层都错位」，不是压缩层间距

x 只能落在 48 网格上、洞宽 144、层间留 24
→ **相邻两层洞的中心差数学下限就是 192**。

所以第一版把「靠壁」写成"每层都开在 96"是白写的：它撞层间 24，
候选被推到 ±192 外，最后一层 96、一层 288，读作"随机抖动"，不读作"靠壁"。
六种骨架现在**每种都自带错位**（两列交替 / 左右交替 / 左中右轮转），
这才是它们彼此的差别来源。

### 层间 24 不能动（试过，退回来了）

为了给骨架更多位移空间，曾把层间 24 放宽成"允许重叠 48"。
**六条断言立刻红**：`相邻两层洞从不重叠` / `每个洞正下方都接得住` / `没有怪吊在半空`。

原因：层间一旦重叠，两层洞连成一口 2 层高的竖井，掉下去直接穿两层 ——
而且洞宽还是 144，玩家从上层掉下去可能直接落到下层的洞边上，**读作死局**。

结论写回代码注释：**数学上没必要（下限本来就是 192），玩法上有害。**

## 二、深潜（无尽）：一命到底

**同样零新内容** —— 生成器 / 骨架 / 饱食条 / 结算卡片全是现成的。

| | 主线 | 深潜 |
|---|---|---|
| 层数 | 2 → 5 随 stage 涨 | 固定 5 |
| 关卡来源 | `stage` 曲线 | 深度 × 7919 + base 派生种子 |
| 过门 | `phase='clear'` → 下一关 | `diveNext()`，深度 +1 |
| 资源 | 每关重置 | **原样带过去**，只补 1 点 hp |
| 死亡 | 缓一缓再复活 | 不复活，直接结算 |
| 分数 | 无 | 深度×100 + 肚里余粮×3 + 击杀×5 |

HUD 上唯一的进度量就是「深度」那个小芯片（图 02 左，试验台面板正下方）。

### 踩坑：深度芯片和试验台面板整块重叠

**只有出图才看得见。** 深度芯片原本在 `806..944 × 74..108`，
「试验台」面板是 `704..944 × 82..170` —— 芯片整块被盖住，
「最佳」那行（y=122）还正好落在面板的第三行字上。

改到左上（`16..154 × 74..108`）又撞操作提示条（y=96）。
最后落在**同一列的 y=178**：右侧自上而下读作「试验台 → 深度 → 最佳」。

补丁不是改数字，是**把矩形集中成 `HUD_RECTS` 表**，断言直接量"任两个矩形不许相交"。
这类 bug 读代码看不出来（两边都是硬编码数字，改一处不会提醒另一处）。

## 三、出图本身返工了四次

评审图本身也是交付物，糊了就等于没做。

| 版本 | 出图上读作 | 改成 |
|---|---|---|
| ① | 960×450 硬塞进 468×112（横 0.49 / 纵 0.25），洞的位移全被压平 | 每层 300×140 等比，3 列 × 2 行 |
| ② | 标题行互相压（"直井 洞 x = …"和"之字"叠在一起） | 标题挪到卡片上方，`TOP` 132→172 |
| ③ | 每张卡片画的是**同一关**的洞 | 洞在 `reset` 时抄进 `cards`，不在循环里读 `L.S.level`（那已经是最后一关了） |
| ④ | 粉框浮在楼板上方的空中 | 框跨在楼板线上（320..360，楼板占 330..356） |

深潜那张同样：结算页 960×600 塞进 235×294（横 0.245 / 纵 0.49）字全糊
→ 改成**不缩整屏，1:1 裁出卡片那一块**（420×300，四周留 20）。

**注意**：出图必须用 stage 25~30，不能用 stage 1~6 ——
前 6 关是 2 层教学关，只有 1 个洞，六种骨架里有五种在那里退化成"洞开在某列"。
