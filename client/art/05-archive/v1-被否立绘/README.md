# 废弃的出图（保留作迭代记录，不进任何产物）

| 文件 | 被否的原因 |
|---|---|
| `01-年糕-初版-与砂糖同姿态被否.png` | 技术和画风都合格，但用了「站正 + 举爪 + 领巾 + 头顶呆毛」这个姿态模板 —— 一眼看过去和砂糖是同一只。**同质化的真正来源是姿态模板，不是配色。** 改成坐姿前倾 + 垂耳 + 卷尾螺旋 + 摇尾残影后通过。 |
| `02-星屑-初版-侧身导致头小眼小被否.png` | 侧身三分之四回望，眼部面积被压缩，成了六只里**唯一头小眼小**的一只 —— 传说位反而最不吸引人。改回**正面站正** + 巨尾从身后甩出后，头和眼睛才画得够大。 |

同一个坑矢量版也踩过两次（v2 的狐闭眼、v2.2 的狐被 clip 裁掉巨尾）。
结论写进 `docs/混合生产管线_PAWPACK_v3.0.md` §10.2：**六只一律正面取景，传说位不例外。**
