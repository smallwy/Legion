# PAWPACK 主界面 · 交互热点家族规格 v1.0

> 目标引擎：Cocos Creator 3.8.8 · 设计分辨率 1280×720（横版，fitHeight）
> 适用对象：路标「任务」挂牌、工作台 / 图鉴 / 灶台 / 派遣 / 去苔原 五个场景徽标、出门按钮
> 状态：**规格待确认**，基准图已出（`shots/ui-bench/`）

---

## 0. 结论

这 7 处读起来像「系统控件」而不是「游戏物件」，原因不是配色，是**载体的三处结构性缺失**。最硬的一条证据：

> **圆徽描边 2.75px，名字底板描边 0.75px —— 同一个元素的两个零件，描边差 3.7 倍。**

放一起必然读成「贴纸 + 贴纸」，因为它们的重量根本不是一个家族的。其余两条缺失见 §1。

本规格要做的不是"再调调"，是把徽标从**浮动形状**改成**一块有厚度的挂牌**，并把四态、字号、点击区一次定死。

---

## 1. 诊断（每条都有量出来的数字）

| # | 症状 | 量化证据 | 根因 |
|---|---|---|---|
| 1 | 贴纸感 | 圆徽 47×48 与胶囊 37×23 是两个**独立**底板，靠「间距 46px」硬对齐 | **无载体**：没有"一块牌子"这个实体 |
| 2 | 纸片感 | 牌面纯色 `#FFFCF4`，零内高光、零落影、零内阴影 | **无厚度**：场景是水彩厚涂（有明暗有笔触），UI 是纯平的，不在同一个打光下 |
| 3 | 描边断层 | 2.75px vs 0.75px（3.7 倍差） | **家族五要素未定义**，各零件各画各的 |
| 4 | 图标弱 | 图标 29px、线宽 2.75px、完全居中 | 字库图标语言（机械几何 + 细线），与手绘世界冲突 |
| 5 | 文字挤 | 名字 **11px**、行高 **11**（比值 1.0）；资源卡标签 **10px** | 低于 12px 下限；行高 1.0 让中文笔画上下顶边 |
| 6 | 点击区不足 | 徽标 47×47，触屏最小 88×88 | 视觉尺寸与点击区未分离 |

第 5 条是"看起来廉价"最隐蔽的成因：11px 的中文在小徽标下已经没有任何笔画细节，只剩灰块。

## 2. 家族五要素（定死，全族逐项复用）

| 要素 | 规格 | 依据 |
|---|---|---|
| **载体形态** | 圆角**方牌**（不是圆形） | ① 场景里路标、告示板、木牌、告示牌全是方形，圆形在这个世界里只属于**宠物头像**（6 个头像是唯一圆形），徽标再用圆会与头像撞语义；② 方牌能容纳横向更宽的图标（灶台的锅）；③ 方牌 + 下方同宽缎带是一条竖直的"牌"，读起来是一个整体，圆 + 胶囊是两个不同曲率的形状，读起来是散的 |
| **圆角半径** | 边长 × 0.25（48 → **12px**） | 0.25 是"糖牌"区间：> 0.30 读成胶囊，< 0.15 读成硬角方框 |
| **描边** | **3px**，色 `#684024`，全族统一 | 现有 2.75px 取整到 3（像素栅格）；名字缎带也必须 3px，现在 0.75px 是断层源头 |
| **留白率** | 图标占牌面 **61%**（48 → 29px） | 60%–64% 视觉权重最稳；> 70% 读成"撑满到边"，< 55% 读成"缩在中间" |
| **光源** | 左上 45°，内高光只在**顶部与左侧** | 与场景一致（屋顶高光在左、云影落右下） |

### 2.1 牌面色：三档实测，选 C

同一个形状只换牌面色，肉眼判断差别极大（见 `shots/ui-bench/28-四方向对比.png`）：

| 档 | 牌面渐变 | 描边 | 实测结论 |
|---|---|---|---|
| A 白陶 | `#FFFAEE` → `#EED8BA` | `#6E462C` | 干净工整，但和场景像**两个图层**——白得太跳 |
| B 暖木 | `#E7C698` → `#CB9E6C` | `#7A4E2A` | 融进场景了，但和工作台、木门、路标**同色相撞**，边界发糊 |
| **C 暖奶油（推荐）** | **`#FFF6E2` → `#F2DCB8`** | **`#684024`** | 有厚度、**不跳**、边界清楚。白陶的骨架 + 木牌的暖调 |

落地色值以 C 为准。牌面必须**带竖向渐变**，纯色填充无论调哪个色号都是纸片。

## 3. 尺寸阶梯 + 材质分层（本规格最关键的一条决策）

**47px 的牌上，水彩笔触和木纹只剩 1–2px 的随机噪点 —— 那不是质感，是脏。**

所以同一家族必须分两个细节层级，这也是 `icon-system.md` 里"小尺寸必须单独简化，禁止用大图缩放充数"的直接应用：

| 层级 | 显示尺寸 | 材质做法 | 落地方式 | 对象 |
|---|---|---|---|---|
| **S 小件** | ≤ 64px | 简化：3px 描边 + 2px 顶部内高光 + 3px 落影。**无笔触、无木纹** | Graphics 程序化绘制（零美术资源、可换色、任意缩放不糊） | 5 个场景徽标（48×48）+ 名字缎带 |
| **L 大件** | ≥ 96px | 完整：水彩笔触 + 木纹 + 厚度内阴影 | 贴图 + 九宫格 | 出门按钮 460×76、派遣卡 132×116、任务木牌 |

**一句话**：小件靠"厚度分层"取胜，大件才配得上"材质笔触"。给 47px 的徽标贴水彩木纹贴图 = 花资源买噪点。

## 4. 状态矩阵（四态，缺一不可）

| 态 | 牌面填充 | 描边 | 图标 | 内高光 | 位移 | 用途 |
|---|---|---|---|---|---|---|
| **常态** | 渐变 `#FFF6E2` → `#F2DCB8` | `#684024` 3px | `#8A5A32` | 2px `rgba(255,255,255,0.58)` | 0 | 默认 |
| **按下** | 渐变 `#F2E2C6` → `#DCBF95` | `#563319` 3px | `#6E462C` | 无 | y −2 | 触到瞬间 |
| **选中** | 渐变 `#FFF6E2` → `#F2DCB8` | `#E08A3C` 3px | `#C4702A` | 2px `rgba(255,255,255,0.70)` + 外环 2px `rgba(224,138,60,0.45)` | y +1 | 有未读 / 焦点 |
| **锁定** | 渐变 `#E8DECC` → `#D2C2A8` | `#A8977F` 3px | `rgba(138,90,50,0.38)` | 无 | 0 | 未解锁 |

**落地红线**：**按下只动明度，不动色相。**
第一张基准图里按下态被生成成了橙红，读起来是"换了块料"而不是"被按了"。按下 = 牌面降 2 档明度 + 下沉 2px，色相不变。

**落影（四态共用）**：offset (0, +3)、blur 4、`rgba(92,58,32,0.26)`。按下态落影收到 blur 2 —— 牌压下去了，影子跟着收紧，这才有"按进表面"的实感。

## 5. 逐项规格

### 5.1 场景徽标（工作台 / 图鉴 / 灶台 / 派遣 / 去苔原）

当前 5 个全部 `47×48`、anchor `(0,1)`、位置：

| 节点 | 当前 pos | 当前尺寸 |
|---|---|---|
| Badge-工作台 | (-390, -12) | 47×48 |
| Badge-图鉴 | (-163, 31) | 47×48 |
| Badge-灶台 | (-35, 53) | 47×48 |
| Badge-派遣 | (385, -115) | 47×48 |
| Badge-去苔原 | (-379, 181) | 47×48 |

**改动**

| 项 | 当前 | 规格 | 依据 |
|---|---|---|---|
| 视觉尺寸 | 47×48 | **48×48** | **不放大。**第一版曾按 56 做，实测白色面积增加 42%，四个牌在草地上比原来更跳 —— "设计感"不等于"更醒目"。48 是 4 的整数倍（像素栅格），且与原尺寸几乎一致，视觉重量不变，提升全部来自质感 |
| 圆角 | 正圆 | **12px** | 0.25 × 48，见 §2 |
| 外描边 | 2.75px | **3px** | 取整到栅格 |
| 图标 | 29px 细线 | **29px，块面（非细线）** | 61% 留白率；关键不是变大，是**从线稿换成块面** |
| 名字字号 | 11px / 行高 11 | **12px / 行高 16** | 12 是用户定的下限；行高 16 = 1.33 倍，中文笔画不再顶边 |
| 名字缎带 | 高 23、描边 0.75px、宽 37~48 | 高 **24**、宽 **48（与牌同宽）**、圆角 **6**、描边 **3px** | 宽度随文字变会出现"工作台宽、图鉴窄"，四组并排是一列参差不齐的标签；同宽才读作"牌的签名条"。圆角 6 与牌 12 是同族比例（0.25） |
| 缎带间距 | 徽标下沿 −2px（CAP_GAP 46） | 缎带顶边压在牌下沿上方 **2px**（CAP_GAP 46） | 保持"压上去"，不是"浮在下面" |

**位置无需改动**：尺寸从 47×48 到 48×48，视觉中心不变，`pos` 保持原值。

**点击区（独立于视觉）**

| 项 | 规格 |
|---|---|
| 点击区尺寸 | **88×88** |
| 实现 | 现有的 `Badge-x-hot` 节点直接放大到 88×88，中心与视觉牌对齐 |
| 依据 | 触屏最小命中 9mm ≈ 88 逻辑像素 @720 高；视觉保持 56 不动 |

这是"视觉尺寸与点击区分离"——**不要为了好点而把牌子画大**，那会把场景糊住。

### 5.2 任务挂牌（路标中间那块木板）

| 项 | 当前 | 规格 | 依据 |
|---|---|---|---|
| 字号 | 15px | **17px** | 木牌净区 62×28；17×3 字 = 51px，左右各留 5.5px；15px 在 28px 净高里只占 54%，读作"木牌上有个小 logo" |
| 字色 | `#56321A` | `#4A2C14` | 加深一档，与木色拉开 |
| 刻字感 | 无 | Label 加 **1px 深色 outline** + 字下移 1px | 真刻字无法用单张 Label 做双层，outline 是等效近似；要更真则需"字 + 亮色偏移副本"两层 Label |
| 点击反馈 | 有 | 按下时**整块木牌** y −1 | 移牌不移字，字跟着牌动 |
| 点击区 | 84×76 | **88×76** | 宽度补到 88 下限 |

### 5.3 派遣卡（L 件）

尺寸 `132×116 @ (406,-156)` 已对，**保持不变**（上一轮才按像素量过）。要补的是质感：

| 项 | 规格 |
|---|---|
| 圆角 | 22（保持） |
| 外描边 | 4px `#7A5034` |
| 内圈浅描边 | 2px `#D6B08C` @ 0.82，内缩 9px |
| 牌面 | `#FFFCF4`，**不透明**（`#F5EBE0` 上会让背景白横线透出 5% 鬼影，已踩过） |
| 落影 | offset (0,+4)、blur 6、`rgba(92,58,32,0.24)` |

### 5.4 出门按钮（L 件，主行动）

当前 460×76。尺寸**保持**，全部改在"厚度"上：

| 项 | 当前 | 规格 | 依据 |
|---|---|---|---|
| 填充 | 纯 `#F2BA6C` | 竖向渐变 `#FFC65C` → `#F2A03C` | 顶部亮底部暗 = 圆柱受光，读作"厚片"而不是"色块" |
| 外描边 | 2~3px | **4px `#8A5426`** | 主行动要比徽标（3px）重一档，层级才成立 |
| 顶部内高光 | 无 | **3px `rgba(255,255,255,0.55)`**，离边 5px | 这是"糖衣"的关键 |
| 底部内阴影 | 无 | **6px `rgba(150,90,30,0.35)`** | **厚度的唯一来源**。没有这条，无论渐变怎么调都是平的 |
| 圆角 | 38 | **38**（= 高/2，胶囊） | 保持 |
| 落影 | 无 / 很弱 | offset (0,+4)、blur 6、`rgba(120,70,30,0.28)` | — |
| 「出门」 | ~32px，字距偏大 | **32px / bold / `#5C3618`**，字距 0 | 现在是等宽点阵感，"出"与"门"之间被撑开，读作 HTML button |
| 「能量 100」 | 12px，位置随意 | **14px `#8A5426`**，与左侧文字基线对齐 | — |
| 右箭头 | 1px 细线三角 | **实心三角 14×18**，右端内缩 24px | 细线箭头在琥珀底上只有 1px，等于看不见 |

## 6. 图标清单（5 个需重画为块面风格）

统一：画布 **29×29**（源图 116×116 @4x）、正投影、无透视、**块面填充**（不是细线稿）+ 左上单侧高光、无文字、图形占画布 61%。

| 名称 | 主体 | 剪影要点（涂黑后必须能区分） | 命名 |
|---|---|---|---|
| 工作台 | 锤子（斜置 45°） | 长柄 + 单侧方头，柄尾粗 | `icon_hot_bench_116@v1.png` |
| 图鉴 | 摊开的书 | 中央书脊凹口 + 两侧页边呈扇形 | `icon_hot_codex_116@v1.png` |
| 灶台 | 带盖的锅 | 宽圆锅身 + 顶部提环，锅耳左右各一 | `icon_hot_stove_116@v1.png` |
| 派遣 | 信封 | 矩形 + 上部 V 形折口 | `icon_hot_send_116@v1.png` |
| 去苔原 | 靴印 / 脚印 | 脚掌 + 3 个脚趾点，方向朝右上 | `icon_hot_go_116@v1.png` |

> 示意图里这 5 个是用 `tools/_ui_icons.py` 程序化画的占位块面（`shots/ui-bench/`），**形状方向对，细节需美术精修**——尤其「锤子现在读成了 T 字」「锅的提环在 29px 下会和锅沿粘在一起」这两处。

**可辨识性四测**（不过即重做，不是"再调调"）：
1. 100% 尺寸（34px）距屏 50cm，0.5s 内认出
2. 75% 尺寸（26px）仍能认出
3. 涂黑剪影，5 个之间两两可区分 —— **书和信封最容易糊成同两个方块，必须靠"书脊凹口 vs V 形折口"拉开**
4. 转灰度，仅靠明度可区分

**没有 ttf 资源**：项目里 `assets/` 下没有任何字体文件，全部走系统字体。所以字号/行高规格是**唯一**的排版控制手段，不能指望换字体解决。

## 7. 落地方式

| 对象 | 方式 | 理由 |
|---|---|---|
| 5 个徽标 + 缎带 | Graphics 程序化（roundRect 分层） | 尺寸小，笔触无意义；可零资源换色、任意分辨率不糊 |
| 出门按钮 | 贴图 + 九宫格 | L 件，要水彩质感 |
| 派遣卡 | 贴图 + 九宫格（或保持 Graphics + 落影） | 中件 |
| 任务木牌 | 保持背景图（牌是画进 bg 的）+ Label | 牌体不可分离 |

**Cocos 九宫格参数（四个具名值，不写顺序）**

| 资源 | left | top | right | bottom | Sprite Type | 备注 |
|---|---|---|---|---|---|---|
| 出门按钮底板 | 44 | 44 | 44 | 44 | SLICED | 圆角 38 + 描边 4 + 内高光 3，44 = 38 + 余量 6，保证两端圆头不被拉伸 |
| 派遣卡底板 | 28 | 28 | 28 | 28 | SLICED | 圆角 22 + 内圈描边 9 |

> ⚠ Cocos 的 Border **绑在 SpriteFrame 上**，一个 SpriteFrame 只有一套九宫格参数。出门按钮与派遣卡若共用同一张底板图，必须出两张。

**图集分组**：`ui-home-common`（徽标 + 缎带 + 派遣卡的贴图）、`ui-home-big`（出门按钮，长条 2048 上限内独占）、`ico-hot`（5 个热门图标，全部 136×136）。
