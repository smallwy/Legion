## 0. 结论先行

**可行。而且是这个项目目前最自洽的一条主线。**

但"可行"不等于"照你说的直接加"。有三个结构性矛盾不先修掉，做出来会同时违反立项红线①和融合铁律 5（玩法数量与创新度成反比）：

| # | 矛盾 | 为什么致命 | 本方案的解法 | 改动面 |
|---|---|---|---|---|
| 1 | 立项红线①写着**「不做线性关卡线」**，而你要的是"长主线 + 关卡推进" | cozy 玩家被卡关就退款，这是立项第 1 条铁律的原话。做成"第 1 关→第 50 关"直接踩线 | **长主线 = 产地节点地图，不是关号。** 同一个产地去几次都行，推进的是"这张图能走多深"，不是"你到第几关了"。**没有关卡失败，只有收获变少** | 红线措辞要改，意图不变 |
| 2 | 你已定**一局只带一只**，但立项是**六宠编队 + 系统 C 关系网** | 单角色后，"同类相邻 +20% / 异类 -15% / 抢食 / 嫉妒 / 护主"**全部失效**——它们全都要求多宠同场 | 六只从"编队成员"改成"**解法池**"：每只 = 一套关卡解法。关系网**降级**（见 §6，这条必须你知情） | 系统 C 要重构 |
| 3 | 你要"模拟经营 + 关卡推进"，这是两个玩法 | 铁律 5 的判决是：**"宠物+五个玩法都松"永远输给"宠物+一个玩法极紧"**。《桌宠大乱斗》就是这么死的 | 经营**不做第二个玩法**，只做"**规则修改器**"：家园产出的每一样东西都直接改写关卡规则，不改数值 | 家园系统要收窄 |

**一句话概括这版主线**：

> **出门前挑一只宠物、带两件家里做的道具，去一个产地；在产地里一屏屏往里推，能推多深推多深；能带回多少吃的，全看你把球往哪儿推。**

## 1. 可行性调研

### 1.1 市场先例（已有底稿，这里只做结论引用）

| 案例 | 结构 | 对我们的意义 | 数据可信度 |
|---|---|---|---|
| 《咩咩启示录》COTL | 家园 + 十字军远征（15 分钟/次），死亡只丢临时增益、资源保留 | 证明"关卡作为资源入口"能撑爆款（850 万份 / 3 人团队） | 中偏高 |
| 《Stay: Your Forever Pet!》 | 养一只宠 → 每天一起出门远征 → 带回资源装饰家 | **2026-07 刚 EA、97% 好评**，和我们的构想最同构 | 中偏高 |
| 《NekoAruki》 | 派猫出门 → 等 → 带回纪念品 → 填图鉴 | 证明"性格影响产出"这条螺丝有效 | 中 |
| 《雪人兄弟》Snow Bros | 单屏清场、裹敌成球、推球连锁、50 关线性 | **动词和关卡元素**的来源 | 高 |

**结论：结构有先例，动词有先例，但"把两者焊在一起"的产品我没有找到直接对标。** 这既是机会也是风险——见 §7。

### 1.2 结构可行性：雪人式的"单屏"和"长主线"到底冲不冲突

**这是整个可行性判断的核心。** 不冲突，但必须换一种串法。

| | 雪人兄弟原版 | 直接照搬会怎样 | 本方案 |
|---|---|---|---|
| 关卡单元 | 单屏清场 | 单屏很好，问题在"串" | 保留单屏 |
| 串法 | 50 关线性 + 命数 + 超时即死 | 违反红线①②（卡关 + 失败惩罚） | **一屏接一屏的"推进链"，可以随时收工回家** |
| 失败 | 死光 → 重来 | cozy 玩家退款 | **没有死光**。被打掉的是"这一趟背着的东西"，不是进度 |
| 重复 | 关卡打完就过 | 内容量爆炸（原版 50 关是 8 个人做的） | **产地可以反复去**，每次地形组合和敌人配置有变化 |

**关键设计转换：把"关卡"换成"产地"，把"过关"换成"走多深"。**

```
第 1 关 → 第 2 关 → 第 3 关        （线性，卡关，踩红线）
        ↓ 换成
苔藓林（可反复去）
  ├ 浅层 3 屏   ← 随时能来
  ├ 中层 4 屏   ← 需要工具
  └ 深层 5 屏   ← 需要道具 + 特定宠物
```

这样一来：
- **有推进感**（我想把这棵树走到底）
- **没有卡关**（走不下去就少带点回去，明天再来）
- **内容量可控**（4 个产地 × 3 层 ≈ 12 张图，而不是 50 关）

### 1.3 深度可行性：用立项自己的深度公式检验

立项文档里定的公式：**深度 = 简单规则 × 大量相互作用 × 频繁决策**，判断标准是"玩家脑子里想的是『我在打怪』还是『我在凑一个组合』"。

雪人式的核心规则极简（**糊 → 滚 → 推**，三个动词），这满足"简单规则"。但它单靠自己也撑不住长主线——原版 50 关靠的是"新地形不断出现"。所以深度必须从"相互作用"和"决策频率"里来：

| 深度来源 | 现状（grove.html 原型） | 撑长主线需要补 | 补法 |
|---|---|---|---|
| 简单规则 | ✅ 已有（糊/滚/推） | — | 不加动词，**这条守住** |
| 大量相互作用 | ⚠️ 只有 3 种地形 × 6 种弹道 | 需要地形之间、地形与角色之间成矩阵 | 见 §4.3 / §4.4，**不加系统，只加组合** |
| 频繁决策 | ✅ 每 3 秒一次"往哪儿推" | 需要把"出门前决策"也变成高频 | 见 §4.5，带什么道具 / 带哪只宠 |

**自检（铁律 1）**：「把宠物删掉换成一把枪，游戏还成立吗？」
- 如果宠物只提供弹道 → **成立 → 融合失败**
- 本方案的对策：**宠物提供的是"这一屏怎么解"，不是"打多少伤害"**。删掉宠物，你就没法用抛物线越过枯木桩、没法用超宽判定堵窄道 → **不成立 → 融合成立**

**自检（铁律 5）**：一句话能不能说清？
> ✅「养一群小动物，出门把怪物糊成球，推着球去撞更多怪物，带吃的回家。」

说得清。所以经营部分必须**只保留能被这句话概括的部分**，其余全砍（见 §5.1）。

### 1.4 单人开发量评估（诚实版）

| 模块 | 现状 | 要做的量 | 依据 |
|---|---|---|---|
| 雪人式核心手感 | ✅ `grove.html` 已跑通（51 项断言，机器人 38.2s 清场） | 小幅调优 | 实测 |
| Cocos 侧移植 | ❌ 零改动 | **+1200~1600 行**（平台跳跃 + 推球物理 + 自写 AABB） | CR-022 §6.2 估算 |
| 关卡内容 | ❌ 只有 1 张空地 | **12 张图**（4 产地 × 3 层），靠元素组合 | CR-022 §6.1 |
| 家园经营 | ❌ 无 | 收窄后约 **1 屏 + 3 个功能** | §5.1 |
| 存档 / 元进度 | ❌ 无 | 单机存档即可，无后端 | 立项阶段 5 前全单机 |

**结论：可行，但"12 张图"是最大的一块成本。** 缓解办法是每张图不手工摆，而是"地形元素池 + 规则生成"—— 同一产地每次进，元素的**位置**变、**规则**不变。这样 12 张图能撑上百次出门。

## 3. 长主线结构：产地地图 + 推进链

### 3.1 三层结构（Hub-and-Spoke 不变，换辐条）

```
【家园】一屏 · 无时钟
  喂食（饱食度）· 做道具（材料）· 升级产地（解锁更深）
        │
        │  选产地 + 选宠物 + 带 2 件道具
        ▼
【产地】一张野外地图 = 3 层深度
  浅层 3 屏  →  中层 4 屏  →  深层 5 屏
  每屏打完，选：继续深入 / 就地收工 / 撤回
        │
        │  带回食物 + 材料
        ▼
【反哺】食物喂宠 → 半饿最强可用；材料做道具 → 下次能走更深
```

**为什么这就是"长主线"而不是"关卡"**：

| 问题 | 关卡式回答 | 本方案回答 |
|---|---|---|
| 我能过第几关？ | 第 23 关 | 苔藓林我能走到中层第 2 屏 |
| 打不过怎么办？ | 重来 / 卡死 | 就地收工，带少一点回去，做个道具再来 |
| 通关是什么？ | 打完最终关 | 把 4 个产地的深层都走通 |

### 3.2 产地地图（首发 4 个）

每个产地**只教一个新地形机制**，不堆。这是"3 个地点不换皮"的落实（关卡降级设计 §4 坑 3）。

| # | 产地 | 新机制（只教一个） | 它逼出的决策 | 敌人主力 | 解锁条件 |
|---|---|---|---|---|---|
| 1 | **苔藓林** | 火坑（×2 但断连锁）+ 泥坑（强化） | 这一球要钱还是要连锁 | 刺毛虫（走）、乌鸦（飞） | 开局 |
| 2 | **枯木坡** | **枯木桩**（挡弹道，只有球能撞碎）+ 落叶堆（打滑） | 必须造球，不能站桩射 | 小野猪（冲撞） | 苔藓林浅层走通 |
| 3 | **泥沼** | **荆棘**（撞掉手里的球）+ 大泥坑 | 路线有禁区，球不能乱推 | 沼泽蛙（跳） | 枯木坡浅层走通 |
| 4 | **萤火洞** | **弹菇**（球被弹起）+ **兔子洞**（球传送） | 球能打到高处 / 走隐藏路线 | 萤火虫群（盘旋） | 泥沼浅层走通 |

> **第 4 个产地是"啊哈时刻"的位置**：当玩家发现"把球推进兔子洞，它会从另一头出来撞到一整排"时，这条玩法才真正"深"起来。前 3 个产地是在教他掌握工具，第 4 个是让他自己发明路线。

### 3.3 单次出门的推进链（3-5 屏）

```
进图（选宠 + 道具已定）
   │
   ▼
┌─ 第 1 屏 ────────────────────────┐
│  糊 3 层 → 变球 → 推          │
│  清完 → 场上出现 3 个"收成点"    │
└──────────────┬──────────────────┘
               ▼
      ┌────────┴────────┐
      │  继续深入？      │
      ├─────────────────┤
      │ 是 → 下一屏（地形更复杂，收成 ×1.3）│
      │ 就地收工 → 结算，带回已收集      │
      │ 撤回 → 结算，带回 80%（快速离场）│
      └────────┬────────┘
               ▼
        带着东西回家
```

**为什么"就地收工"必须是选项**：这是"没有失败惩罚"的落地方式。玩家永远有一个安全出口，压力来自"我还能不能多贪一屏"，而不是"我能不能过关"。

### 3.4 长线循环（数周的回访理由）

| 时间尺度 | 玩家在追什么 | 系统支撑 |
|---|---|---|
| 一屏（30-60 秒） | 这一球往哪推 | 地形结算 |
| 一趟（3-5 分钟） | 能走多深、带多少回去 | 推进链 + 收成 |
| 一天（15-30 分钟） | 做道具、喂宠、解锁下一个产地 | 家园 |
| 数周 | 把 4 个产地深层全部走通 + 集齐六只宠物的解法 | 产地解锁 + 宠物收集 |

## 4. 关卡深度设计（四层模型）

### 4.1 总览

```
层 4  经营层   带什么道具出门     ← 决策在"出门前"，频率低但权重最大
层 3  角色层   带哪只宠物         ← 决策在"出门前"，决定这一趟的解法
层 2  地形层   这一球往哪推       ← 决策在"每一推"，频率最高（每 3 秒）
层 1  规则层   糊 → 滚 → 推       ← 永不变，三个动词
```

**四层全部挂在"推球"这一个动作上**，没有增加新动词。这是"简单规则"的守线。

### 4.2 层 1：规则层（永不变）

| 动词 | 规则 | 为什么不能变 |
|---|---|---|
| 糊 | 攻击不扣血，只加 1 层苔；满 3 层变球 | 屏幕不需要血条，敌人鼓起来就是进度 |
| 滚 | 球撞到没满层的敌人会把它**卷进球里**，球变大变慢 | 这是"先铺场再引爆"的规划层，原版没有 |
| 推 | 走向球就推走；落地位置决定这颗球值多少 | 核心创新的全部重量压在这里 |

### 4.3 层 2：地形层（元素表 + 每个元素逼出的决策）

> 原则：**每一个地形元素必须绑一条决策，纯装饰的一个都不做。**

| # | 元素 | 规则（改的是规则，不是数值） | 逼玩家做的决策 | 出现产地 | 优先级 |
|---|---|---|---|---|---|
| 1 | **泥坑** | 球裹泥变重，之后每撞一人 **+2 层** | 要不要先把球洗成泥球再推 | 苔藓林 | P0 |
| 2 | **火坑** | 球烧掉，收成 **×2**，**连锁中断** | 贪一把双倍，还是留着球撞更多人 | 苔藓林 | P0 |
| 3 | **营地** | 落袋，收成 ×1 **且额外 +1** | 稳一手还是赌连锁 | 苔藓林 | P0 |
| 4 | **枯木桩** | 挡弹道；**只有球能撞碎**，撞碎掉野果 | 必须造球，不能站桩射 | 枯木坡 | P0 |
| 5 | **落叶堆** | 刹车失灵（`vx *= 0.995` vs `0.82`） | 推球要提前半格松手 | 枯木坡 | P0 |
| 6 | **荆棘丛** | 撞上去**掉手里的球** | 球不能乱推，路线有禁区 | 泥沼 | P1 |
| 7 | **弹菇** | 球踩上去被弹起 → 打到高处的人 | 用什么手段把球送上高台 | 萤火洞 | P1 |
| 8 | **兔子洞** | 球滚进去 → 从另一个洞口出来 | 自己发明"传送连锁"路线 | 萤火洞 | P1 |
| 9 | **野果** | 红=移速 / 蓝=糊得更快 / 黄=推得更远 / 绿=短暂无敌 | 先吃还是先推 | 全产地 | P1 |
| 10 | **单向平台** | 从下能穿上去，上去就下不来（要跳缺口） | 落点要想 | 全产地 | P0 |
| 11 | **漂木 / 藤蔓** | 移动平台 | 时机 | — | **P3，不做**（贵） |
| 12 | **收工钟声** | 天变橘色。**只改结算，不砍人** | 走还是留 | — | **砍掉惩罚，只做氛围** |

### 4.4 层 3：角色层（六角色 × 地形的解法矩阵）

> 这张表是"选谁 = 选解法"的落地，也是单角色出战的**唯一存在理由**。如果这张表不成立，单角色就是纯粹的功能削减。

| 角色 | 弹道形状 | 擅长地形 | 明显打不了的 | 一句话解法 |
|---|---|---|---|---|
| 尖耳猫 | 扇形三发 | 开阔多层，敌人散开 | 窄道（打不全） | 撒网 |
| 短尾犬 | 宽波穿透 | 窄道、贴身近战 | 远程高处 | 堵路 |
| 胖仓鼠 | 高速穿透 | 走廊式一排敌人 | 高处、散开 | 穿糖葫芦 |
| 长耳兔 | 抛物线 + 落点爆炸 | **越过枯木桩**、打高处 | 近身（自己脆） | 隔山打牛 |
| 老实牛 | 超宽贴身判定 | **堵住窄口**、荆棘旁 | 大范围（走不动） | 当墙用 |
| 影狐 | 高速刃 | 快速清场、追杀 | 群怪（单体） | 快刀 |

**矩阵用法举例**（这就是"深度"）：

- **枯木坡中层**：木桩挡住所有直射弹道 → 只有**长耳兔（抛物线越过）** 或 **造球撞碎** 两条路。带猫去就是纯受罪。
- **泥沼深层**：荆棘满地，球一撞就掉 → **老实牛**站在荆棘旁用超宽判定贴着糊，不需要推球，是另一套解法。
- **萤火洞**：敌人全在高台，弹道打不到 → 必须用**弹菇把球弹上去**，或带**长耳兔**抛射。

**关键约束：六个角色里没有"最强"，只有"这张图最合适"。** 这是平衡的设计目标（见 §7.1）。

### 4.5 层 4：经营层（道具 = 规则修改器）

> 这是"模拟经营"和"关卡"焊死的地方。**家园产出的每一样东西，都必须直接改写关卡规则。**

| 道具 | 材料 | 改的规则 | 什么时候想带 |
|---|---|---|---|
| **苔藓罐** | 苔藓 ×3 | 进图时每只敌人自带 **1 层** | 想快速起手，少糊一轮 |
| **火种** | 树脂 ×2 | 火坑**不再中断连锁** | 想贪双倍又不想断连锁（这是最贵的一件） |
| **厚泥靴** | 树皮 ×3 | 落叶堆**不打滑** | 打枯木坡必带 |
| **树脂涂层** | 树脂 ×3 | 球寿命 **+50%**（滚更久才崩开） | 深层图，球要滚很远 |
| **蜜果酱** | 野果 ×2 | 半饿区间 **扩大 20 点** | 想全程吃 ×1.5 火力 |
| **引虫香** | 菌丝 ×2 | 进屏时敌人**聚成一堆** | 想一颗球带走一片 |

**这个设计的价值**：玩家出门前的 30 秒，要想三件事——**去哪、带谁、带什么**。这三件事互相耦合（去枯木坡 → 带厚泥靴 → 带长耳兔越过木桩），而不是三个独立选项。这就是"相互作用"。

### 4.6 深度自检

| 检验项 | 标准 | 本方案 |
|---|---|---|
| 简单规则 | 动词数 ≤ 3 | ✅ 糊 / 滚 / 推 |
| 大量相互作用 | 元素两两组合有意义 | ✅ 12 地形 × 6 角色 × 6 道具，有效组合 > 100 |
| 频繁决策 | 每 3 秒一次 | ✅ 每推一次都要选落点 |
| 玩家在想什么 | "我在凑组合"而不是"我在打怪" | ✅ "带兔+厚泥靴去枯木坡" 就是凑组合 |
| 铁律 1（删掉宠物换成枪） | 不成立才算成功 | ✅ 换枪就没有"抛物线越木桩"这层解法 |
| 铁律 5（一句话说得清） | 能 | ✅ 见 §1.3 |

## 5. 模拟经营怎么咬（不做第二个玩法）

### 5.1 家园只做三件事

> 铁律 5 的判决：**加系统 = 减创新**。所以家园必须窄到一句话说完。

| 功能 | 做什么 | 不做什么（明确砍掉） |
|---|---|---|
| **喂食** | 调饱食度 → 决定出门时的火力倍率（半饿 ×1.5） | 不做 5 条需求条，只做饱食度 1 条 |
| **做道具** | 材料 → 6 种规则修改器（§4.5） | 不做自由摆放、不做建筑树、不做装饰系统 |
| **升级产地** | 材料 → 解锁产地更深一层 | 不做大地图、不做多建筑 |

**明确砍掉的**（这些是"五个玩法都松"的典型）：装饰自由摆放、宠物洗澡、图鉴收集、抽卡、每日任务、排行榜、好友。

> 如果以后要加，一次只加一个，且必须能挂进"糊/滚/推"这条链。

### 5.2 半饿最强怎么接（现成的咬合点）

这是立项系统 B，原本就是"两线咬合的钥匙"。接进来不需要改：

```
家园喂太饱 → 出门 ×1.0（安全平庸）
家园喂七分 → 出门 ×1.5（最强，但宠物会"闹"）
忘了喂   → 出门 ×0.6（危险）
```

**雪人式给它加了一层新意义**：火力倍率不只是"打得多快"，而是**"糊满 3 层要几发"**。
- ×1.5 火力 → 2 发糊满 → 造球快 → 连锁起得早
- ×1.0 火力 → 3 发糊满 → 造球慢 → 容易被围

**于是"喂多少"从一个数值选择，变成了"这趟我想打快攻还是稳推"的打法选择。** 这是白送的深度。

## 6. 单角色带来的两个失效系统（必须你知情）

### 6.1 系统 C 关系网：目前是失效的

立项 §2.3 系统 C 的六条规则，**全部依赖多宠同场**：

| 规则 | 依赖 | 单角色下 |
|---|---|---|
| 同类相邻 +20% | 两只同族距离 < 阈值 | ❌ 失效 |
| 异类相邻 -15% | 两只异族靠近 | ❌ 失效 |
| 抢食 | 两只都饿时靠近食物 | ❌ 失效 |
| 嫉妒 | 只撸一只宠物 | ✅ 仍成立（在家园里） |
| 护主 | 玩家被击中，最近宠物冲锋 | ❌ 失效 |
| 羁绊 | 共同出战 N 次 | ⚠️ 可改为"累计出战" |

**三个可选处理（需要你拍板）**：

| 方案 | 做法 | 优点 | 代价 |
|---|---|---|---|
| **A. 降级为"家园关系"**（我倾向） | 关系只在家园生效：嫉妒、争宠、一起吃食 → 影响"心情" → 心情影响出门时的**初始饱食度** | 改动最小，保留"活物感" | 护城河变浅 |
| B. 改为"宠物之间的传承" | 不带出门的宠物在家"照顾"出门的那只 → 给 buff | 把"军团"感找回来 | 新系统，成本中 |
| C. 暂时不管 | 先做主线，关系网后置 | 最快 | 立项的"唯一差异点"暂时缺位 |

### 6.2 编队 → 解法池

单角色后，"编队"这个词不能用了。改成"**选谁出门**"，且意义从"凑战力"变成"选解法"（§4.4）。

**这其实是升级，不是削减**：编队时六只都在场，每只的差异会被平均掉；单角色时，每只的差异被放大到"这趟能不能打"。这符合 Brotato 的"角色即规则"。

## 7. 风险与代价（说实话的部分）

### 7.1 设计风险

| 风险 | 严重度 | 缓解 |
|---|---|---|
| **"推"变成唯一最优解**（永远推回家最稳） | 高 | 数值上让"一次撞 3 只"的收益明显高于"推回家 3 次"；需要平衡采样（`grove-balance.js` 目前不存在，要补） |
| **六角色平衡做不住**（总有一只是最优） | 高 | 用 §4.4 矩阵做"地形克制"，不做数值平衡；每张图至少让 2 只可用 |
| **Cocos 侧工作量被低估** | 高 | +1200~1600 行（CR-022 §6.2 估算），不能当"改一下" |
| **关卡内容量**（12 张图） | 中 | 元素池 + 规则生成，位置变、规则不变 |
| **cozy 定位被操作难度破坏** | 高 | 不做命数、不做超时；被打只掉"这一趟背的收成" |
| **模拟经营变成"第二玩法"** | 中 | 严格按 §5.1 的三件事，砍掉一切装饰性系统 |

### 7.2 数值骨架（雪人化，替换立项 §2.7）

| 项 | 值 | 说明 |
|---|---|---|
| 玩家血量 | **3** | 原 6 血，因为不再有 20 波持续压力 |
| 无敌帧 | 0.9s | 防连击秒杀 |
| 单屏时长 | 30-60s | |
| 单趟时长 | **3-5 分钟**（3-5 屏） | 原 5-6 分钟 |
| 单屏敌人数 | 6-8 只 | 原单波 6→26 |
| 包裹层数 | **3 层**（满即变球） | 核心 |
| 球初始半径 | 22px，每装一只 +2.8px（上限 +16） | 原型实测 |
| 球阻尼 | 170（滚约 1100px） | 原型调参结果 |

| 球崩开 | 停住 > 4.2s 或寿命 > 26s | 同上 |
| 收成倍率 | 火坑 ×2 / 营地 ×1+1 / 普通 ×1 | |
