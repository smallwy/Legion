# CR-032 · 「吸引玩家」的缺口，与一次品类天花板修正

> 结论先行：**上一轮 CR-028 / CR-030 拿「Snow Bros. Wonderland 约 1,060 份」当推球品类的天花板，这个参照选错了。**
> 真正的同类天花板是 **BALL x PIT 的 200 万份**。品类没有低天花板，低的是「只有打砖块本身」的那些游戏。

---

## 1. 参照点修正

| 游戏 | 定位 | 累计销量 | 说明 |
|---|---|---|---|
| **BALL x PIT** | 打砖块 + 球融合 + 基地建设 | **200 万+** | Devolver 发行，2025-10-15 上线 |
| Meltopia | 打砖块 + 探索/环境解谜 | 5 万+ | 上线不到一个月 |
| Snow Bros. Wonderland | **IP 正统续作，只做打砖块** | 约 1,060 | 我上一轮当成品类天花板 |
| BreakoutQuest | 只做打砖块，点屏幕代替挡板 | 约 13 | 2026-07 上线 |
| Buster Breaks Out | 打砖块 + roguelite，$3.34 | 24h 峰值 3 人 | 2026-03 上线 |

BALL x PIT 的曲线：**24 小时 10 万 → 5 天 30 万 → 3 个月 100 万 → 10 个月 200 万+**，
34,000 同时在线峰值，95% 好评（23,952 条评测）。2026 年做了三次免费大更新
（1 月 Regal / 4 月 Shadow / 7 月 Naturalist）。

**它对自己的描述只有三个动词**：`brick-breaking, ball-fusing, base-building`。

反面对照很干净：上面两个只做打砖块的，一个 13 份、一个 3 人在线。

> **不是"推球品类天花板低"，是"没有第二个系统的推球游戏卖不出去"。**
> 这个差别值 5 个数量级。

⚠️ CR-028 那份调研选的对照是 IP 正统续作 —— 那测的是「IP 值多少钱」，不是「推球值多少钱」。
以后给品类定天花板，必须挑**结构最接近的那个成功者**，不是挑同一个母题里最有名的那个。

## 2. 我们其实已经有那三个系统

| BALL x PIT | PAWPACK | 状态 |
|---|---|---|
| brick-breaking | 糊两层 → 推 → 连锁滚穿 | ✅ 且更强（地形决定收成） |
| ball-fusing | 六把武器 / 包裹层 / 连锁 | ✅ |
| base-building | 家园：灶台 / 工作台 / 派遣 / 亲密度 / 6 只宠物 | ✅ |

**缺的不是系统，是一句话和一个能放进 GIF 的画面。**

差异点也真实存在，必须提前准备好（玩家一定会说"这不就是 BALL x PIT"）：

- 它是 **roguelite**（每局重开）；我们是**关卡制 + 一趟倍率**（`1+0.15×过关数`，收工才结算）。
- 它是"球自己弹，你捡资源"；我们是**"先铺场再引爆"** —— 一颗球的价值由你**提前**糊了几层、
  以及**最后把它推到哪个坑**决定（火坑 ×2 断连锁 / 泥坑加厚 / 营地 +1）。
- 一句话差异：**「它是球撞怪，我们是布局」**。

## 3. 吸引漏斗与我们的位置

```
曝光 → capsule 点击（CTR 2-4% 平均，<3% 要重做）
     → 商店页访问 → 加愿望单（中位 8-12%）
     → 愿望单 → 首日转化 ~5% / 首周 ~20% / 首年 ~60%
```

| 环节 | 基准 | 我们 |
|---|---|---|
| Capsule CTR | 2-4% 平均，4-7% 好 | **没有 capsule** |
| 访问→愿望单 | 中位 8-12% | **没有商店页** |
| retro arcade 品类 | **4-7%（全站最低）** | 按现在的标签会落在这里 |
| factory / automation | 15-20%（全站最高） | 结构上更接近这个 |
| 预告片前 10 秒留存 | 25-40% 算平均 | **没有预告片** |
| 愿望单打底 | 首发 <5,000 且离上线 <6 周 → 建议延期 | 0 |

**最关键的一条**：`retro arcade` 的商店页转化率是 **4-7%**，全站最低；
`roguelite` 是 12-16%，`factory/automation` 是 15-20%。**同一套代码，标签不同，看到你的人差 3 倍。**

而我们的结构（推球 + 家园 + 养成 + 一趟倍率）根本不是 arcade，
**挂 Breakout / Arcade 当主标签，等于主动把自己推进转化率最低的人群。**

## 5. 为什么"一球 5 连"是唯一值得做的 GIF

现在的机制天然长这个样子，但**第一关喂不出这个画面**：

- 武器糊不死人，只糊层 → 必须**先铺场**
- 糊满 3 层 → 变球；已有 2 层的被撞 → 当场变新球、70% 速度继续滚
- 所以「一颗球滚出一场风暴」的前提是**玩家提前把整层各糊了两下**
- 球落地位置决定价值：火坑 ×2 但断连锁 / 泥坑加厚 / 营地 +1

这是一个**"准备 → 引爆"**的结构，视频里 5 秒就能讲完，而且观众会想知道"他是怎么做到的"。
**BALL x PIT 卖的是"球撞怪"，这个卖的是"我算好了"。**

→ 所以第 1 关的目标不是"摸熟操作"，是**"让玩家第一次滚出 5 连"**。
这条改的是关卡配置，不是代码。

## 6. 别把预算花在"画得更好"上

转化率最高和最低的品类差 **3 倍**（factory 15-20% vs retro arcade 4-7%），
差的是**人群**，不是质量。画风已经从"断层"修到"同一套"，边际收益接近 0。

同样一周工作量：

- 投在「再画两套主题」→ 对吸引的作用 ≈ 0
- 投在「一句话 + 一个 GIF + capsule」→ 决定有没有人点进来

| 风险 | 应对 |
|---|---|
| 玩家说"这不就是 BALL x PIT" | 提前把差异写进商店页第一段：**关卡制 + 布局决定收益**，不是 roguelite |
