# Legion · 内核补全与空间包装

> 版本 v1.0 · 2026-10-24 · 触发：用户「不是球的问题 是空间设计的问题 和 创新型问题 现在是照抄雪人兄弟 我要的是内核是他的 表面需要包装 更丰富点」
>
> 前两版结论作废：《空间母题设计》（要新系统）、《先让代价可见》（答偏了，是表现层）。本文只回答一件事：**内核怎么补全，包装往哪放。**

---

## 0. 结论先行

1. **现在不是"照抄雪人兄弟"，是只抄了一半。** 抄了「糊 → 推」，**丢了「弹」**。
2. 证据在代码里：球推出后只有三种结局 —— **撞墙 3 次碎**（`grove.html:4041`）、**进火坑烧掉**、**进营地结算**。**没有一种是"自己弹到停"**。
3. 因为**撞墙是惩罚**，理性玩家永远走直线。**一个惩罚弹墙的雪人兄弟，空间当然只能是平铺** —— 不是不会设计空间，是**规则让空间没有意义**。
4. 最小改动、最大解放：**把撞墙从惩罚改成奖励**。一处逻辑，玩法重心当场翻转。
5. 然后空间包装才有地方放，按成本从低到高：**台面材质（1 个字段）→ 盒子轮廓（要改常量墙，唯一实质工程）→ 视觉材质（纯美术）**。

---

## 1. 两个内核的差别，一句话说清

| | 雪人兄弟 | 现在的实现 |
|---|---|---|
| 球是什么 | **武器** —— 滚过就杀，撞到谁算谁 | **货物** —— 要投递到营地 |
| 球的结局 | 自己弹到停，然后碎 | 撞墙 3 次碎 / 进洞结算（**全是提前终止**） |
| 玩家算什么 | **入射角** | **瞄准线** |
| 空间需要什么 | **墙**（多弹一次多赚一次） | **直线**（墙是障碍） |
| 一球能杀几只 | 3~8（弹一路） | 1~2 |

**货物要瞄准，所以需要直线；武器要覆盖，所以需要墙。**

这条差异决定了一切。现在的"球门（营地）"把球从武器降级成了货物，**营地判定就是弹球玩法的死刑判决书**。

不改判定也能救：**让"弹"变成收益，而不是过程浪费。**

---

## 2. 一处逻辑的翻转（本轮核心）

现在是：

```js
b.wallHits = (b.wallHits || 0) + 1;
if (b.wallHits >= 3) { burstBall(b, "撞散了…"); continue; }
```

改成：

```js
b.wallHits = (b.wallHits || 0) + 1;
b.r = Math.min(46, b.r + 2.4);      // 撞一次，球大一圈 = 能多卷一只
b.vx *= 1.06;                        // 而且更快
```

**效果**：玩家会开始**主动打斜线**，因为"多弹一次 = 多卷一只"。空间立刻从装饰变成研究对象 —— 他会去找"哪面墙能让我多弹两下"。

**这就是雪人兄弟的爽点，而且不需要动营地判定、不需要新地形、不需要新系统。**

**风险（必须由数值角色定）**：

- 与「限球」「零崩」两类关卡正面冲突（零崩关要求球不许碎，改完之后球不会碎了，这条目标自动失效）
- 27 屏的落点、球速、卷人数量全部按当前参数调过，撞墙变大会让连锁数普遍上浮
- 需要给"变大"设一个硬上限，否则一屏能滚出一颗巨球，把整关一次清完

## 3. 空间包装三层（按成本从低到高）

### 第 1 层 · 台面材质（**最便宜，建议先做**）

`plats` 已经有 `kind` 字段（`ground` / `ledge`）。加值就行：

| 材质 | 物理 | 玩家学到什么 |
|---|---|---|
| `ice` 冰 | 摩擦极低，球不减速，越滚越快 | 「球会加速，别让它上冰」 |
| `sand` 沙 | 摩擦高，球很快停 | 「这里能救停我的球」 |
| `crisp` 脆 | 球滚过就碎，一次性 | 「这条路只能走一次」 |
| `bounce` 弹 | 球撞上去弹起（**给球纵向能力**） | 「从上面砸下来」 |
| `sticky` 黏 | 球经过减速并轻微转向 | 「会被掰弯」 |

**同样的地图形状 × 5 种材质 = 5 倍变化，而地图数据只多一个字段。** 这是"更丰富"的最高性价比来源 —— 玩家每次看到新材质都要重新学一遍，但美术只需换一套贴图。

**这一层能独立成立**，不依赖第 2 层。

### 第 2 层 · 盒子的轮廓（**唯一实质工程**）

| 轮廓 | 球的行为 | 图例 |
|---|---|---|
| 矩形 | 可预测，靠入射角算 | 图 2 |
| 梯形（上窄下宽） | 越弹越往中间聚 | 图 3 |
| 凹形（中间低） | 在中间来回振荡 | —— |
| 锯齿墙 | 每次都不一样，值得反复试 | 图 4 |

**技术障碍（诚实说）**：墙现在是**固定常量** `WALL_L = 26 / WALL_R = 934`，所有反弹判定都直接读它。要做梯形/锯齿，必须把"墙"从两个常量改成**多边形轮廓**，并重写反弹法线计算。

**这是本轮唯一的大工程，也是唯一会波及全部 27 屏的改动。**

**务实解法**：第一批**不做斜墙**。用「矩形盒 + 台面材质 + 弹台」就能拿到大约 80% 的效果（因为 `bounce` 材质已经能给球纵向变化）。斜墙放第二批，等第一批验证完再说。

### 第 3 层 · 视觉包装（纯美术，零规则风险）

| 项 | 做法 |
|---|---|
| 墙的材质 | 冰墙 / 石墙 / 藤墙 / 骨墙 —— 跟 6 套产地色板走 |
| 球的形态 | 雪球 / 泥球 / 冰球 / 火球 —— **物理完全一样，只换观感** |
| 碰撞反馈 | 碎冰 / 泥浆 / 火星，按球当前形态出，不同形态不同粒子色 |

**这一层不改任何规则，但玩家感知到的"丰富度"提升最大** —— 因为玩家说"丰富"，说的是**看得见的差异**，不是"规则数量"。

## 4. 具体一屏长什么样

**「冰斗」**（梯形盒 · 但第一批用矩形盒 + 冰台替代）

- 盒子四周封闭，两层 `ice` 台面
- 敌人从上方分批掉下来
- 玩家推一颗球，球在墙间**越弹越快**，滚过冰台，卷走一路
- 玩家唯一要做的判断：**从哪个位置、什么角度推**
- 过关：数量满足（不要求清完）

**和现在一屏的区别**：

| | 现在 | 冰斗 |
|---|---|---|
| 玩家做的事 | 从左推到右 | 选一个入射角 |
| 一球能卷几只 | 1~2 | 3~8 |
| 球撞墙 | 惩罚（第 3 次碎） | 奖励（变大变快） |
| 失败原因 | 球撞散了 | 角度打歪了，球只弹了两下就停 |

**内核一模一样（糊 → 推 → 滚），但玩家玩的是另一件事。**

---

## 5. 实施顺序

| 步 | 内容 | 依赖 | 风险 |
|---|---|---|---|
| **1** | 撞墙惩罚改奖励（变大 + 加速 + 上限） | 无 | 需数值角色定上限；与零崩关冲突 |
| **2** | `plats` 加材质：`ice` / `sand` / `crisp` | 1 | 27 屏落点需重验 |
| **3** | 视觉包装：墙材质 + 球形态 + 碰撞粒子 | 无 | 无（纯美术） |
| **4** | 盒子轮廓（梯形 / 锯齿）→ 需先把墙从常量改成轮廓 | 1~2 验证通过后 | **大工程，波及全部关卡** |

**第 1 步是分水岭**：它决定"弹"到底是不是这个游戏的玩法。做完出一屏对照（同一屏，改前 / 改后，看玩家会不会主动打斜线），再决定要不要往下走。

**第 3 步可以和第 1 步并行**，因为纯美术不碰规则。

---

## 6. 附：关于"创新"的诚实判断

雪人兄弟的内核（糊 → 推 → 滚）已经很好，**不需要创新内核**。真正能创新的位置只有三个：

1. **球推出之后那段**（撞墙变大、材质相互作用）—— 雪人兄弟没做深，**这里空间最大**
2. **球与球相互作用**（已经有速度传递，但玩家没理由制造它）
3. **空间的性质而非形状**（材质比轮廓便宜 10 倍，收益接近）

**"创新"不该花在新地形上** —— 那只是把雪人兄弟的关卡再画一遍。该花在"球飞出你手之后，它自己做了什么事"上。这是它当年没做完的部分。
