# 新玩法设计：深巢（无尽）与星靶（挑战层）

> 2026-10-25 · 起因是用户两句话：
> 「整个游戏 只有 27 关 怎么保证长线的？」
> 「新玩法 我需要你设计出来 你最好把这些玩法用一个概念图 UI 处理好」
>
> 本文是**概念与工程约束**，不是实装报告。代码未动。

---

## 1. 病根（为什么必须加，而不是再装饰一层）

| 现状 | 数据 |
|---|---|
| 27 屏内容量 | 20~50 分钟，一次性吃完 |
| 五个入口的代价 | 主线 / 任务 / 工坊 / 派遣 / 评级，**零个要求玩家放弃什么** |
| 永久成长出口 | 改造件 4 件，且只能买一次 |
| 评级 | `S.best[i]` **只落盘零奖励**，刷 S 没有回报 |
| 派遣 | 只能派 1 只，60s/趟封顶 10 趟 ≈ 100 果，同期打屏 300~600 果 |
| 同质化根因 | 7 种目标 27 次使用**全是计数型/禁止型**，没一种要求「球必须走某条路」 |

结论：**是循环不是螺旋**。玩家第 1 小时和第 10 小时能力相同。
加装饰、加文案都不解决这个问题 —— 没有沉淀就没东西可展示。

## 2. 两个玩法，一次说清

### 玩法 A · 星靶（挑战层）— 低成本，先做

- **形状**：27 屏各挂 3 个挑战条件，共 **81 个**。
- **条件本身是空间型的**（这是它顺带治好同质化的原因）：
  - 「让一颗球从坡顶滚下入营」—— 坡第一次和胜利条件相关
  - 「一球卷三只进营」—— 直接对冲「球免费 → 卷球负收益 50%」那条
  - 「不打冰壳通关」「用球 ≤ par」「一趟内触 3 次弹菇」
- **奖励**：集满一屏 3 靶 → 图纸碎片 2 + 该屏改造件折扣。
  这修掉「刷 S 没有回报」—— 从「一个字母」变成「一个可累积的东西」。
- **为什么先做**：纯数据 + 结算埋点，**不动关卡几何**，
  ALL9 的 1031 条断言基线一根都不用改。风险接近于零。
- **UI**：结算卡从「一个评级字母」改成三颗可点开的靶；
  图鉴页照现有「挑一屏」的 3 行 × 9 列摆 81 格（深/中/浅 = 三章）。

### 玩法 B · 深巢（无尽）— 长线的答案，后做

- **形状**：一路下潜，深度无上限。每层 = 一个随机地形屏 + 一个目标。
- **地形怎么来（关键工程约束）**：**不从零随机生成几何**。
  从现有 27 屏的几何原语（坡 / 浮空台 / 弹菇 / 障碍 / 营地位置）里
  **按深度加权抽样重组**。物理一套不变，只换排列 ——
  这样 `updateBalls` / `predictBall` 不用动，ALL9 基线不用动。
  从零生成新几何会同时炸物理、寻路、机器人三条线，不做。
- **词条（每 5 层一个）**：规则修改，不是数值修改。
  深 5「球更重 · 推力 −15%」/ 深 10「只能带 2 颗球」/
  深 15「敌人翻倍」/ 深 20「没有预瞄线」+ 断台。
  词条**可以在看板上关掉**（花巢币买「不生效」）—— 这给了玩家一个选择，
  而「有选择」正是现在五个入口最缺的东西。
- **收成**：按深度换算巢币 + 碎片。深度越深，单位时间收益越高，
  但词条越极端 —— 贪不贪的张力回来了（现在通胀 6.5× 已经把这条线废了）。
- **没有失败惩罚**：掉出 / 被打 = 只丢**这一层**的收成，
  已到达的深度记录永久保留。符合硬红线 3。
- **出口**：巢币 → 改造件从「4 件买一次」扩成「可叠层数」，
  这是全项目目前唯一缺失的「永久变强」。

## 3. 落地顺序（待拍板）

| 顺序 | 事项 | 动什么 | 风险 |
|---|---|---|---|
| 1 | 星靶数据 + 结算埋点 + 结算卡 UI | `config/Stages.ts` 加字段、`GroveBattle` 结算、`HomeRuntime` 结算卡 | 低，不碰几何 |
| 2 | 巢币 + 改造件可叠层数 | `HomeBiz` / `SaveData` | 中，要迁存档 |
| 3 | 深巢地形抽样器（只重排，不新建） | 新文件 `config/Nest.ts`，读 `LEVELS` | 中，要新的机器人口径 |
| 4 | 深巢词条 + 看板 + 局内 HUD | `GroveBattle` / `HomeRuntime` | 高，词条会改规则 |
| 5 | 用 ALL9 之外的第二套机器人跑深巢（现在只有 hero=2 被验证过） | `tools/` | — |

**明确不做**：
- 不做多宠并行派遣（一宠出征、六宠看家，改成数组要迁存档）
- 不做失败惩罚
- 不从零随机生成几何
- 不给深巢单独做第二套物理
