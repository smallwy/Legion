# 深巢地形生成设计（无尽模式 · 地形层）

> 2026-10-25 · 起因是用户一句话：
> 「深巢无尽模式 我需要改变地形 需要改变新鲜感」
>
> 本文只设计**地形层**。词条 / 巢币 / 改造件可叠见
> 《Legion-新玩法设计_深巢与星靶_20261025.md》，不重复。

---

## 1. 结论：地形靠六个手段变，风险分三档

「从 27 屏原语里抽样重排」是原方案，实测家底后**判定不够**：
重排只是把 152 个平台洗牌，坡仍然只有那 6 条、营地仍然在右边，
玩家第 3 层就认得出「哦还是那些台子」。六个手段按风险排：

| # | 手段 | 变的是什么 | 物理风险 | 工作量 |
|---|---|---|---|---|
| 1 | **整屏镜像** | 出生点/营地/坑位左右对调 | **零**（对称等价） | 极小 |
| 2 | **主题轮换** | 8 种 theme 按深度换皮肤 | **零**（theme 是纯皮肤） | 极小 |
| 3 | **构件重组** | 27 屏 = 27 个已验证配方，抽配方组装 | 低（都是验证过的构件） | 中 |
| 4 | **参数扰动** | 台长 ±15% / 坑宽 ±20% / 坡角在 ≤32° 内 | 中（要可达性校验） | 中 |
| 5 | **危险密度曲线** | 坑的种类/数量/间距按深度开放 | 低（坑是既有 kind） | 小 |
| 6 | **波次配方轮换** | 敌人组合按深度从池里抽 | 零（waves 是纯数据） | 小 |

手段 1/2/6 加起来就能让前 20 层「每层都长得不一样」，且一条物理断言都不用改。
手段 3/4 是结构新鲜感的来源，靠**生成后校验**兜底（见 §4）。
手段 5 是难度曲线，不是新鲜感，放一起因为共用深度轴。

## 2. 家底盘点（生成器的原料）

| 构件 | 总量 | 生成器怎么用 |
|---|---|---|
| 平台 `plats` | 152（27 ground + 125 ledge） | 拆成「台面片段库」，按 x/y/w 三元组入库 |
| 坡 `ramps` | **6** | 稀缺件。深巢按深度加权：浅层 30% 层有坡，深层 80% |
| 坑 `pits` | 75（火 29 / 泥 29 / 水 17） | 危险度主来源。火=双倍收成+烧球风险，泥=减速，水=沉 |
| 营地 `camp` | 27/28 在 x≈852 | 镜像后变左侧，是**没开采过**的新鲜感 |
| 主题 `theme` | 8（tundra/snow/cliff/tower/stairs/slope/well/bouncy） | 纯皮肤轮换，零风险 |
| 敌人 `foe` | 5（bug/boar/crow/larva/boss） | 波次配方池 |
| 目标 `goal` | 7（clear/collect/chain/limit/intact/bank/nohit） | 每层挂 1 个，按深度开放 |

关键事实：**坡只有 6 条**。主线把坡当稀缺教学件（26..620 一条道教「球会自己滑」），
深巢里它应该仍然是「这层有个坡，认出来」的事件，不是标配。

## 3. 生成器结构：三层分离

```
第 N 层地形 = theme(N) × skeleton(N, seed) × jitter(seed, N)
                   视觉层        结构层              参数层
```

### 3.1 theme 层（零风险）

8 主题按深度轮换，同深度内不连续重复：
`theme(N) = THEMES[(N + floor(N/3)) % 8]`，浅色主题（tundra/snow）在浅层权重高，
深色（well/cliff/tower）在深层权重高。**纯换色，物理一个数不动。**

### 3.2 skeleton 层（结构）

不「从零随机几何」，而是**槽位组装**。每层按固定槽位从构件库抽件：

| 槽位 | 约束 | 候选来源 |
|---|---|---|
| 地面 | 恒 1 段（`kind: ground`，贴 WALL_L..WALL_R） | 27 屏同款 |
| 低台层 y≈462 | 1~3 段，段间留口（球不能顶死墙角） | 库内 462 层片段 |
| 中台 y≈350 / 高台 y≈248 | 按深度开放 0~2 层 | 库内片段 |
| 坡 | 0~1 条，必须连接相邻层且**坡顶接台、坡底落地** | 6 条已验证坡的参数区间 |
| 坑 | 0~3 个，地面层，宽度受 §4 约束 | 火/泥/水三池 |
| 营地 | 左或右（镜像决定），`w=82` 不变 | 同款 |
| 木桩 | 0~2，按深度 |  stump 片段 |

「槽位 + 已验证片段」而不是「随机坐标」—— 每一段都来自 27 屏里
机器人真跑通过的几何，物理边界天然在验证集内。

### 3.3 jitter 层（参数扰动，受约束）

在抽中的片段上做小扰动，让「同一配方」长出不同手感：

| 参数 | 扰动范围 | 约束来源 |
|---|---|---|
| 台长 w | ±15% | 最短 ≥ 120（球径 36 + 转向余量） |
| 台 x | ±40，不越墙、不与邻台重叠 | 槽位边界 |
| 坑宽 | ±20% | 最宽 ≤ 140（= 主线已验证的可跳过宽度） |
| 坡角 | 在既有区间内浮动 | 峰值 ≤ 32°（注释里的 2.4·H 规则） |
| 冰面 | 0~1 段，宽 100~160 | 主线 2 屏同款参数 |

**扰动后必须过 §4 校验，不过就回退到未扰动版**（保守治疗：
宁可不新鲜，不可不可玩）。

### 3.4 深度解锁表（新鲜感的时间轴）

| 深度 | 结构开放 | 主题 | 目标池 | 词条 |
|---|---|---|---|---|
| 1–5 | 地面 + 1 层台 + ≤1 坑 + ≤1 坡 | tundra/snow | clear, collect | 无 |
| 6–15 | +中台，木桩，冰面；营地开始镜像 | 全 8 轮换 | +chain, limit | 每 5 层 1 个 |
| 16–30 | +高台，坑 ≤2，火坑权重升 | 深色权重升 | +intact, nohit | 每 5 层 1 个 |
| 31+ | 全开放，坑 ≤3，窄台权重升 | 全轮换 | +bank | 每 5 层 1 个 |

每层生成完先过校验再进游戏 —— **深层不是「更难的地理」，
是「更极端的已验证组合」**，不存在没验证过的新几何。

## 4. 可达性硬约束（生成后校验，不是生成时猜）

生成器出口必须全绿才准进游戏，任一不过 → 回退：

| # | 校验 | 做法 |
|---|---|---|
| C1 | 人到得了营地 | 简化 BFS：台面 + 坡 + 地面作节点，落差 ≤ 起跳高度作边 |
| C2 | 球滚得到营地 | 用 `predictBall` 同源判定（**必须逐字同源**，见 DETAILS 教训） |
| C3 | 没有顶死墙角 | 台左端不贴墙（主线 96..300 同款留口），或右端留口 |
| C4 | 坑不连成墙 | 相邻坑缘间距 ≥ 120 |
| C5 | 坡不钻台底 | 坡跨度不得整体落在某台面的 x 区间正下方（主线踩过的坑） |
| C6 | 出生点不落坑里、不在木桩嘴边 | 出生点落地面净空 ≥ 100 |

C1/C2 是**验收**不是生成指导：生成可以随便抽，校验不过就重抽
（上限 20 次，仍不过则回退到上一深度配方微调版）。

## 5. 波次与目标（纯数据轮换，零物理风险）

- **波次配方池**：从 27 屏 waves 提炼组合模板
  （一排 5 bug / 高低双层 / boar 冲锋 / crow 飞行 / boss 收尾），
  按深度抽「模板 × 数量缩放」，敌人密度曲线 = `1 + depth/20`。
- **目标**：每层 1 个，从该深度开放池抽。`limit`/`collect` 额度字段
  按深度收紧（ballLimit = max(3, 8 - depth/6)）。
- **BOSS**：沿用主线「每层结尾 1 只」，lv 按深度涨（`lv = 1 + floor(depth/6)`，封顶 5）。
  深巢不改 BOSS 三动作（slam/fan/spawn 是敌人来源 + 走位时机，硬红线）。

## 6. 验证方案（深巢的第二套机器人）

主线 ALL9 只验证 hero=2 一条参数。深巢**不许**只靠它：

| 验证 | 做法 | 通过线 |
|---|---|---|
| 批量可达性 | 对 depth 1..60 各生成 10 个种子，跑 C1~C6 | 100% 过（校验器本身可信） |
| 机器人试玩 | hero ∈ {1,2,3} × 每 10 层抽 1 层 | 通关率 40%~90%（低于 40% 太难，高于 90% 太水） |
| 时间分布 | 记录每层用时 | 中位数 30~90s，与主线同量级 |
| 回归 | 主线 27 屏 ALL9 基线**一根不动** | 深巢是独立 LEVELS 分支，不进 ALL9 |

## 7. 风险与明确不做

| 风险 | 缓解 |
|---|---|
| 扰动让某层变不可玩 | C1~C6 全过才进游戏；机器人试玩通过率兜底 |
| 「随机地形」玩家不买账（要的是设计感） | 槽位组装 + 已验证片段 = 每层都像人摆的，不像噪声 |
| 深巢代码膨胀拖垮主线 | 新文件 `config/Nest.ts`，主线 27 屏一个数不动 |

**不做**：
- 不从零随机生成几何坐标（炸物理/寻路/机器人三条线）
- 不给深巢单独做第二套物理
- 不新建构件 kind（ledge/ground/ramp/pit/mud/fire/water/ice 全用现成的）
- 深巢关卡不进 ALL9 基线（独立验证流）

## 8. 落地顺序（接原设计文档第 3 节）

| 步 | 事项 | 产出 |

| N3 | 主题轮换 + 镜像 + 波次/目标池 | 同文件扩 |
