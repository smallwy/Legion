## 1. 风格锚点（每批提示词逐字复用，不改写）

> **Q 版手绘水彩卡通风**。2D 侧视。光源来自右上，暖色轮廓光。所有物体统一 **3–4px 深棕实色描边**（`#1D2628` ~ `#754E2D`）。材质靠**手绘笔触与堆叠结构**表达，不靠渐变：木头是**分块的板**（每块独立圆角 + 顶面高光 + 暗部），不是一根圆角条。背景三层纵深：前景灌木（最暗、最饱和）→ 中景树与平台（中调）→ 远景山与天空（最亮、降饱和 30%）。比例约 **3.5 头身**的动物，手脚短、头大。色彩走**暖秋**：奶白、暖黄、焦糖棕、鼠尾草绿。**禁忌**：纯色平涂无描边、锐利直角、冷色（蓝紫）主光源、写实材质贴图、镜面高光、背景与主体同明度。

## 2. 色彩板（从概念图取样）

### 场景
| 用途 | 色号 | 说明 |
|---|---|---|
| 描边 / 最暗部 | `#1D2628` | 所有物件的描边色，**不随主题变** |
| 天空高光 | `#F6DF99` | 远景天空上半 |
| 天空过渡 | `#EECB6C` | 远景天空下半 |

| 木质中调 | `#9B6134` | 平台侧面 |
| 木质暗部 | `#50362D` | 平台底面 / 桩子 |
| 草地暗部 | `#666A4B` | 前景灌木 |

### UI
| 用途 | 色号 | 说明 |
|---|---|---|
| 面板底 | `#F9E7C7` | 奶白 |
| 面板底暗部 | `#EDD6B1` | 面板内阴影 |
| 面板描边 | `#754E2D` | **3.4px 实色**，全项目统一 |
| 强调 / 主按钮 | `#F9CB4A` | 招牌黄 |
| 危险 | `#B0453A` | 只用于失败状态 |

### 明度阶梯（用于检查「主体跳不跳出来」）
| 层 | 明度 L | 内容 |
|---|---|---|
| L1 最暗 | 8–20% | 描边、前景灌木剪影 |
| L2 | 25–40% | 平台侧面、木桩、BOSS 暗部 |
| L3 主体 | 45–65% | **角色、敌人、球** —— 只允许这一层出现饱和暖色 |
| L4 | 70–85% | 平台顶面、中景树 |
| L5 最亮 | 90–97% | 天空、UI 面板 |

**当前违反**：草地背景整体落在 L4，和猫（L3）只差一档 → 主体不跳。修法是把草地压到 L3 下限、加暗绿前景灌木到 L1。

## 3. 现状评审（六维度）

| 维度 | 分 | 问题 | 具体改法 |
|---|---|---|---|
| 剪影可读性 | 3 | 平台剪影是"长条胶囊"，八个关卡全一样；玩家分不清"台面 / 桩子 / 坡"在剪影上有什么区别 | 平台改成**堆叠木板**：每块独立圆角、错缝 1–3px；桩子改成**两根交叉木** |
| 明度层级 | 2 | 背景草地 L≈70、主体 L≈55，只差一档；灰度图下猫和草地糊在一起 | 草地压到 `#4E7A3A`，前景灌木 `#2C4A2A`，主体保持现色 |
| 构图与负空间 | 3 | 平台横条占满画面，负空间只有天空一块；Boss 屏会把整个横向塞满 | 每屏至少留 1 块 160×120 的纯背景负空间 |
| 风格一致性 | 2 | **只有平台有描边**。树、灌木、木桩、火坑、营地箱全无描边 → 一套画面里两种语言 | 所有物件按 3–4px `#1D2628` 统一描边 |
| 技术合规 | 4 | 尺寸/透明底没问题；但平台砖缝是 1px 硬线，缩放到 0.6 以下会产生摩尔纹 | 砖缝改 2px 且带 0.35 透明 |
| 可用性（UI） | 3 | 描边过细（已修）；进度条空槽与底同色（已修）；按钮非胶囊（已修） | — |

**结论分档：`重做`（场景层）／`小改`（UI 层，已改完）**

## 5. 落地清单

### P0（决定"像不像一套游戏"）
1. **平台材质**：`drawPlat` 改成堆叠木板 —— 顶面 `#DAAC5B` + 板缝 `#9B6134`（2px，0.35 透明）+ 侧面 `#9B6134` + 底面 `#50362D` + 统一 3px `#1D2628` 描边。**几何不动**，只改绘制，八关冒烟断言不受影响。
2. **背景分层**：现在只有"渐变 + 山丘弧"，加一层**前景暗绿灌木剪影**（L1，`#2C4A2A`），把草地压到 L3。
3. **树 / 灌木 / 木桩补描边**：统一 3px `#1D2628`。

### P1（手感与辨识）
4. 坡道的木板缝要**跟着坡面曲线走**（现在 `rampSurfY` 已经有了，缝的间距改成沿弧长等分）。
5. 火坑 / 营地木箱 / 那口蓝色小碗（收成目标）改成有描边的实体，现在像纯色贴片。
6. 敌人（虫）加**暗部色块**：现在只有 `c1/c2/c3` 三档纯色，缺少手绘的明暗交界线。

### P2（锦上添花）
7. 天空加一层**云的手绘轮廓**（现在只有圆形色块）。
8. 平台边缘加**草皮覆盖**（概念图里平台两端有草）。
9. 六只宠物的立绘**体量统一**：现在牛偏大、兔偏瘦，同屏并排像三个画师画的。

## 6. 需要拍板的

1. **平台材质重画**要不要做进这一轮？工作量约 1 天，几何不变、八关冒烟可保住。
2. **草地压暗**会让整体从"亮绿"变"暖黄绿"，画面情绪会变。确认要不要走这个方向。
3. 六只立绘**体量统一**需要重出图（现在的牛 / 兔 / 仓鼠比例差很多），要不要排期。
