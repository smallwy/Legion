# 双循环方案（割草战斗 + 家庭宠物养成）· 市场与可落地性深度调研

> 用户最新设计：**战斗** = WASD 只控制一个中心点，最多 6 只宠物围绕该点自动战斗，**战斗中不喂养**；**养成** = 独立的"家庭风格宠物模拟养成"线，喂养发生在这里，并反哺战斗。
> 本文回答两个问题：**这个设计有可行度吗？市场多大？一个人用轻美术能不能落地？**

---

## 〇、一句话结论

**可行，且比"战斗里喂食"更聪明。** 但有一个前提决定生死：**不要把它卖成"又一款子弹天堂"，要卖成"可以带宠物去战斗的治愈系宠物养成游戏"。**

- 割草（Action Roguelike / Bullet Heaven）本身已是**红海**，单独靠战斗卖点突围成功率低于 Steam 均值。
- 但"**战斗 + 家庭宠物养成**"这个双循环，被《咩咩启示录》在 **850 万份** 量级上验证过（它本质就是"基地养信徒 + 地牢战斗"）。
- "Cozy / 宠物"标签的成功率（11%，是 Steam 均值的 **2.6 倍**；$20+ 定价更达 **45%**）远高于动作肉鸽。
- **轻美术在这个设计里是"双重资产"**：战斗需要可读性，养成需要可爱——你的核心约束在这里反而被加倍奖励，这在所有候选方向里是罕见的。

## 二、可行度评估（针对"你这个具体设计"）

### 2.1 战斗（中心点 + 最多 6 单位环绕自动战斗）

- "6 单位环绕中心点"是**已被验证的机制**（Brotato 6 武器槽、20MTD 伙伴、VS 随从）。
- "自动战斗 + 玩家只走位"是 **survivors-like 的正统**（VS / Halls of Torment 本就自动开火）。
- **不战斗里喂养 = 战斗循环干净**，不塞实验性机制 → 你之前担心"无聊"的风险大幅下降，因为活跃循环是整个独立游戏界最 validated 的爽循环。
- 技术可行性极高：6 单位 + 玩家 + 敌潮，Godot + Jolt + 对象池轻松跑数百敌（见此前性能调研）。

### 2.2 养成（家庭风格宠物模拟）

- 这里是 **cozy 赛道主场**，成功率 11%（2.6×均值），且你的轻美术是资产。
- "喂养反哺战斗" = COTL 的"信徒虔诚→战斗强度"同构，已被 850 万份验证。
- 养成深度来源（**不靠堆系统，靠交叉**）：
  - 每只宠物有性格/特质（呼应此前"涌现"研究）→ 影响战斗行为（激进型/防御型/辅助型）。
  - 亲密度/饱食 → 战斗属性倍率（"你养得越好，它打得越猛"）。
  - 收集 6 只不同宠物组队 → 队伍搭配深度（轻量 squad-building）。
  - 家园少量装饰/升级 → 给宠物 buff（轻量经营）。
- **关键：两个循环必须交叉喂养**，否则就是两个半成品。COTL 的做法：地牢赚资源→扩建基地→更强地牢。你的做法：战斗赚资源/素材→回家养宠物/升级窝→宠物更强→战斗更顺。

### 2.3 总体可行度

| 维度 | 评级 | 理由 |
|---|---|---|
| 市场契合 | 🟢 高 | cozy 标签成功率 2.6×均值；$20+ cozy 45%；双循环被 COTL 验证 |
| 战斗趣味 | 🟡 中（需打磨） | survivors-like 红海，手感必须自己站得住，不能靠养成兜底 |
| 美术可行 | 🟢 高 | 轻美术在战斗(可读)+养成(可爱)双场景都是资产 |
| 技术可行 | 🟢 高 | Godot + Jolt + 对象池，6 单位 trivial，单人可做 |
| 范围风险 | 🔴 高 | **两个游戏**，养成线最易膨胀成完整生活模拟 → 必须强制"一屏" |
| 定位风险 | 🔴 高 | 卖错标签（子弹天堂）会掉进 3.5% 成功率坑；必须卖"cozy 宠物" |

**综合：可行度 = 高，但成败由"定位 + 范围纪律"决定，不由创意决定。**

## 三、可落地性（一个人 + 轻美术，能不能做出来）

### 3.1 技术

| 模块 | 工作量 | 说明 |
|---|---|---|
| 战斗（俯视、中心点移动、6 单位环绕自动开火、敌潮波次） | 中 | 你已有"多宠物自动施法"原型可复用 70% |
| 养成（单屏、1–6 只宠物、喂养/互动动画、状态持久化） | 低–中 | 单 2D 屏 + 少量交互，技术 trivial |
| 存档（跨局持久化宠物等级/亲密度/收集） | 低 | 标准 JSON 存档 |
| 性能 | 低 | Jolt + 对象池，数百敌同屏无压力 |
| **合计** | **单人完全可行** | 引擎 Godot（Brotato 同款） |

### 3.2 美术（轻美术 = 最便宜的部分，却产出最高价值）

- **宠物**：设计 6–12 个原型，每个含 待机/进食/开心/睡觉 动画；用 **调色板换色 + 形体微调** 复用。
- **敌人**：8–12 种（换色即可）。
- **家园**：单屏背景 1 张。
- **成本区间**：约 **¥4000–15000**（含养成线动画，比纯战斗版 +¥3000 左右）。若自己画则趋近 0。

### 3.3 时间与范围（关键护栏）

| 阶段 | 周期 | 范围纪律 |
|---|---|---|
| 战斗原型 | 4–6 周 | 复用既有多宠原型 |
| 养成单屏原型 | 4–6 周 | **强制：一屏、无二手系统** |
| 内容 + 平衡 + 打磨 | 3–4 个月 | 6 宠物 + 12 敌 + 10 升级 |
| 商店页 + Next Fest + EA | 1–2 月筹备 | 走 Brotato 节奏：Demo→Coming Soon→Next Fest→EA→高频更新 |
| **到 EA 总计** | **约 6–9 个月（单人）** | 现实可达 |

### 3.4 成本

- Steam Direct **$100**（满 $1000 返还）。
- 美术外包 **¥4000–15000**（或 0）。
- 营销：Next Fest **免费**；可选付费愿望单广告。
- **总现金投入约 ¥5000–20000**。极低。

## 四、风险与规避（诚实清单）

| 风险 | 严重度 | 规避 |
|---|---|---|
| **战斗红海，单独卖点不够** | 🔴 | 差异化全靠养成线；商店页/标签主打 cozy+pet，不主打 bullet heaven |
| **双循环受众分裂**（动作党嫌养成慢、cozy 党嫌战斗紧张） | 🔴 | 养成线做成"快速可跳过"（一键回战斗）；战斗保持可读不高压；语气统一治愈 |
| **养成线范围膨胀成完整生活模拟** | 🔴 | 铁律：**养成=一屏**。不做得像《模拟人生》，做得像"回家撸两把猫再出门" |
| **战斗手感弱，玩家流失** | 🟡 | 战斗手感是硬指标，必须自己爽；可玩原型先验收"走位躲怪潮紧不紧张" |
| **两个循环脱节 = 两个半成品** | 🟡 | 强制交叉喂养：战斗资源→养家；养得好→战斗强 |
| **定价错（定太低）** | 🟡 | cozy 数据表明 **$20+ 成功率 45%**；建议 **$14.99–19.99**，别定 $4.99 |

## 五、定位与定价建议

1. **主标签顺序**：`Cozy` → `Pet` → `Action Roguelike` / `Bullet Heaven`（把 cozy 放最前，吃高成功率坑）。
2. **一句话卖点**："在温馨小家里养好你的伙伴，带它们出门，它们会为你而战。"
3. **定价**：**$14.99–19.99**（cozy 高价反而更可能成；别陷入 $4.99 低价陷阱）。
4. **发行节奏**：Demo → Coming Soon（≥2 周）→ **必参加 Next Fest** → EA（每周更新）→ 1.0。Brotato 真护城河是"节奏"不是技术。

## 六、现实预期（锚定，别飘）

- 🚫 **别锚定 COTL 的 850 万**：那是 Devolver 背书 + 3 人团队 + 暗黑可爱反差人设的特例。
- 🚫 **别锚定 Brotato 的 1000 万**：那是 $4.99 + 移动端 + 单人极简的 outlier。
- ✅ **现实基线**：
  - 下限（创意成立但发行一般）：**MOCHI-O 量级 = 数千份 / $20K–40K 毛利**。
  - 中值（cozy+pet 钩子落地、定位正确）：**Cat Cafe Manager 量级 = ~9 万份 / ~$90 万毛利**。
  - 上限（撞上 Next Fest 爆款 + 好发行）：数十万–百万份。
- 记住：**"好评率衡量满意度，评测数才衡量规模。"** 先求"被看见"（cozy 标签帮你在前 11%），再求规模。

## 七、建议的下一步（原型）

现有两个原型（单宠战斗喂食版、多宠自动施法版）按你的新设计**已过时**（战斗里不再喂食）。建议做一版**双循环可玩原型**：

1. **战斗屏**：WASD 移动中心点，3–6 只宠物环绕自动开火，波次 + 经验 + 升级（复用多宠原型）。
2. **家园屏**：单屏，1–6 只宠物，点击/拖拽喂食，宠物有饱食/亲密度，数值实时显示。
3. **交叉**：战斗赚的"食材/金币"回家可喂；宠物亲密度 → 战斗火力倍率。
4. **验收问题**：①走位躲怪潮紧不紧张？②回家撸宠物爽不爽？③"它因为我养得好才打这么猛"有没有感受到？

> 范围铁律刻在原型里：**家园永远只有一屏，不点开第二个房间。**

- **高可信（Steam 官方/商店数据）**：Bullet Heaven 标签 2026-05-18 上线；各游戏 Steam 评测数/好评率/定价。
