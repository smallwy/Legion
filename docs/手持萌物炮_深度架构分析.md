# 手持萌物炮 · 深度架构分析

> 用户问题：「这个（手持萌物炮）能做起来深度吗？」
> 一句话结论：**能。但"萌物炮"是外壳，深度必须来自叠在它上面的四层系统；否则你会精确复刻 MOCHI-O 的"核心玩法很快就腻"。**

---

## 一、先厘清：萌物炮本身不提供深度

"手持一只 Q萌 生物当炮、主动瞄准开火、信赖乘进火力"——这层只解决两件事：**上手爽感**和**操作skill ceiling**。它不构成"深度"。

证据：MOCHI-O（最终兵器鼠鼠，本方向标杆）恰恰有这套外壳，却被 FinalWeapon 评测判了死刑——"核心玩法很快就腻""后期屏幕变视觉垃圾场""全是自动攻击你只能干等"。**它的外壳好看，但里面没有让玩家第 10 局还想研究的东西。**

好消息：我们 Demo 的**手动瞄准**（MOCHI-O 是自动开火）反而比它多一层操作深度。所以"动作层"你已经领先标杆了；真正要补的是**内容/重玩层**。

---

## 二、深度从哪来：四个单人可落地的深度层

下面每层都给了**真实对标**（都是小团队做出深度的活样本）+ **单人可行性** + **美术成本**。

### L1 · 操作深度（已具备，需保留）
- **是什么**：主动瞄准 + 走位 + 微调阵位替代站桩。
- **对标**：《20 Minutes Till Dawn》（单人 Flanne 开发 / Erabit 发行，5.8M 下载 / 15.4 万评测 / 4.59 分）——手动瞄准让它比自动射击"更难但更带脑"。
- **关键**：**绝不做成自动攻击**。这是 MOCHI-O 头号死法。我们 Demo 已守住。
- **美术成本**：0（机制层）。

### L2 · Build / 组合深度（核心，必做）
这是单人轻美术最便宜的深度来源——**用"状态空间的数学复杂度"代替"美术内容的堆量"**。

三条可选路径，按单人适配度排序：

| 路径 | 对标 | 单人可行性 | 美术成本 |
|---|---|---|---|
| **A 程序化萌物装配**（头/身/耳/元素自由组合→上千种生物） | 《Cassette Beasts》融合系统 **14,000+ 组合**（Bytten 二人组 / Godot / Raw Fury / OpenCritic 85） | ★★★★★ 完美契合 | 极低（复用部件精灵，呼应"16×16 精灵衍生数十帧"杠杆） |
| B 升级树 + 进化协同 | 《20 Minutes Till Dawn》**80+ 升级 + 50+ 武器进化 + 元素连锁** | ★★★★☆ | 低（图标+数值） |
| C 装配/词条协同 | 《Brotato》**40+ 角色各异数值缩放 × 6 武器类 × 道具连锁**（10M+ 销量 / 96% 好评） | ★★★★☆ | 低（武器/道具图标） |

**最推荐 A**：它把本方向最大的美术劣势（要画很多生物）直接变成优势——你只需画"头/身/耳/尾/元素光环"各十几种部件，程序化拼装就能产出上千只**每只都有名字、属性、技能组合**的萌物，且每只都"想被截图"。这等于用 Cassette Beasts 级的组合深度，换近乎零的边际美术成本。**这是单人轻美术唯一能撬动"万级内容"的杠杆。**

### L3 · 元进度（跨局留存，解决"很快就腻"）
- **是什么**：让一局结束后的成长**带到下一局**，给长期目标。
- **对标**：《20 Minutes Till Dawn》击杀攒 Soul → 永久强化 Rune；打 Boss 拿 Tome 大幅增力；Darkness 难度 0→15 层层加压。
- **为什么必须**：MOCHI-O 没有元进度 → 每局一模一样 → 第 3 局就腻。**元进度是"很快就腻"的解药。**
- **单人做法**：信赖等级/解锁的部件/进化形态跨局保留；难度档位递增（参照 Brotato Danger 0-15）。
- **美术成本**：0（存档+数值）。

### L4 · 敌人 / 难度梯度 + BOSS（逼迫 Build 适应）
- **对标**：《Brotato》**25 种敌人**各异攻击模式 + Danger 0-15 复合负面修正；《20 Minutes Till Dawn》多舞台（森林/神殿/南瓜田）各异节奏。
- **作用**：没有敌人多样性，Build 永远一套通吃 → 深度塌缩。敌人梯度是"逼你每局重新想 Build"的发动机。
- **单人做法**：程序化敌人（换色+换移动/攻击模式）+ 每 N 波一个机制不同的 BOSS。
- **美术成本**：低（换色+少数专属精灵）。

## 三、深度杠杆 vs 美术成本（总表）

| 深度层 | 提供什么 | 单人可行 | 美术成本 | 对标验证 |
|---|---|---|---|---|
| L1 手动瞄准/走位 | 操作 skill ceiling | ★★★★★ | 0 | 20MTD |
| L2A 程序化萌物装配 | 组合爆炸（万级内容） | ★★★★★ | 极低 | Cassette Beasts 14k |
| L2B 升级树+进化 | Build 多样性 | ★★★★☆ | 低 | 20MTD 80+ |
| L2C 装配/词条协同 | 流派构筑 | ★★★★☆ | 低 | Brotato 40+角色 |
| L3 元进度 | 长期目标/抗腻 | ★★★★★ | 0 | 20MTD Rune |
| L4 敌人/难度梯度 | 逼迫适应 | ★★★★★ | 低 | Brotato 25敌/D15 |

**结论：六层里五层美术成本=0 或极低，且全部有单人/小团队成功先例。** 深度不是钱的问题，是"你愿不愿意做系统"的问题。

---

## 四、三个必须避开的坑（MOCHI-O 翻车点）

1. **无元进度 / 每局重置** → 第 3 局就腻。必须做 L3。
2. **升级池太浅**（MOCHI-O 只有三选一且无连锁）→ Build 三天穷尽。必须做 L2 的协同连锁（20MTD 的元素连锁、Brotato 的道具协同才是重点）。
3. **自动攻击变观众**（幸存者like 通病）→ 玩家变观众。必须保持 L1 手动瞄准有意义。

---

## 五、给单人轻美术的最推荐深度配方

> **手动瞄准（L1） + 程序化萌物装配（L2A） + 轻元进度（L3） + 程序化敌人梯度（L4）**

- 一只你手里的小生物 = **装配出来的**（头A+身B+耳C+元素D → 名字/属性/技能自动生成）。
- 你喂它、撸它 → 信赖涨 → **信赖解锁更高阶部件槽位**（把"养成"变成 L3 元进度的具象化）。
- 每局：手动瞄准打怪 → 掉素材 → 装配/进化你的萌物 → 局间信赖与部件保留 → 下局更难但你能打更花。
- **这正好呼应前面所有报告的核心法则**：宠物是"玩法的显示器"（信赖=火力）、养成不是仪式是战术决策（撸它=攒资源）、Q萌美术杠杆率最高（部件拼装=万级内容）。

**一句话**：萌物炮能做出深度，条件是把"可爱"当皮肤，把"装配 + 元进度 + 敌人梯度"当骨架。骨架做对，单人也能摸到 Cassette Beasts / Brotato 级的重玩深度。
