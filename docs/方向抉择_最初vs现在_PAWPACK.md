## 〇、结论先行

**选「最初」——但必须先把「最初」说准，它自己变过一次。**

而且这个"变过一次"正是问题的根源：**你现在说的（百炼英雄式），是在用"换骨架"去修一个"被降级的战斗"，换错了地方。**

> ✅ **2026-10-20 已拍板：主干选甲**（用户确认）。登记为 **CR-015**，代码已落地。
> 采纳的具体形态：**甲做主干 + 丙只做表现层**（列队跟随保留）+ 乙的半径制敌人 AI 保留。
> 已实现：20 波怪潮 / 局内升级三选一 / 战斗中喂食（半饿 ×1.5）/ 肉块掉落 / HUD 饱食度条。
> 落地验证：`tsc --strict` 0 error；`tools/sim_wave_balance.py` 算出约 5.5 分钟一局、
> 升级 41 秒一次、半饿窗口 80 秒。

## 一、先对齐「最初」指哪一版

"最初想做的"在文档里演化了两版，加上现在的第三版，一共三版：

| 代号 | 出处 / 日期 | 形态 | **玩家每秒在做什么** | **战斗的地位** |
|---|---|---|---|---|
| **甲 · 原点** | 《最终方向推荐》10-14 前 | 肉鸽割草 + 宠物状态（Brotato 骨架 × MOCHI-O 心脏） | 走位躲潮 + **看准时机喂食** | **主体**（20 分钟一局，爽感即产品） |
| **乙 · 计划书** | 计划书 v1.0 / **CR-001** | 双线互补：战斗**不**喂养，家园 Hub | 走位清场 → 回家喂 | **手段**（3 分钟"出门找食"产资源） |
| **丙 · 现在** | **CR-014** | 佣兵团like：列队跟随 + 清窝 + BOSS | 走位带小队 + 看技能 CD | **主体**（但要靠数值面板撑） |

**关键分水岭是 CR-001，不是 CR-014。**

CR-001 之后，战斗从"爽感主体"降级成了"产出食物的手段"。降级之后的后果是可推算的、也是必然的：

| 战斗是手段 → | 现在的实际值 |
|---|---|
| 只要能打赢、带回资源 | 一局 **57 秒**（不需要更长） |
| 不需要深度 | 每窝只打 **5.2 秒**（系统来不及展开） |
| 反正回家才养成 | **局内成长 = 0**（经验珠只计数不进计算） |
| 不需要操作 | 只有走位、无技能（`HeroSquad` 无 HP、无 CD） |

**推论：现在 demo 的"不好玩"，根在 CR-001，不在"骨架不是百炼英雄"。**

丙（换骨架）没有解决这条因果链——它只是给一具"战斗不重要"的身体换了套更好看的衣服。心脏还是没装回去。

## 二、三条硬证据：为什么丙（佣兵团like）不能当主干

### 证据 1：这个品类的爽感来源，单人+买断拿不到

腾讯新闻 2024-04 对《百炼英雄》的拆解（转引，可信度中）：

> 《百炼英雄》「**技能'割草感'机制缺失**」→「割草体感**对英雄面板依赖性较强**」
> 《轰隆隆佣兵团》「通过**相对较短技能CD**形成割草体感，由相对低CD的无限复活机制使得游戏前期爽感强大」

即：这个品类的爽 = **数值面板 + 短 CD 群伤 + 无限复活** 三件套。

而《百炼英雄》的位置是**微信小游戏畅销榜 TOP3**（九九互动），核心循环是「强卡关 → 付费/养成 → 加速通关」。
《轰隆隆佣兵团》（韩国 PlayHard，本品类原型）全球下载 850 万次 / 流水约 1000 万美元（点点数据估算，可信度中）—— **ARPU 极低，靠的是免费+内购/广告模型。**

**我们既没有"上百英雄+装备+天赋"的面板深度（单人做不出），也没有付费加速这个爽感来源（Steam 买断制没有这一环）。**

⚠️ 事实边界：以上全部是**手游/小游戏**数据。我在 Steam 上**没有搜到**佣兵团like 的成功样本——但我不能因此断言"Steam 上没有"，这一点请你自己在 Steam 搜 `Rumble Heroes like` / `Hero Squad` 核实，别把我的搜索当结论。

### 证据 2：这个品类的差评，逐条命中我们 demo 的现状

台服《轰隆隆佣兵团》长评原话（5 条，可对照）：

| # | 差评原话 | 我们 demo 的现状 |
|---|---|---|
| 1 | 「對傭兵的操作只能透過移動」 | ✅ 只有移动 |
| 2 | 「雖然是操作傭兵團，但這些人**總是各打各的**，完全感覺不出是隊友的感覺」 | ✅ 三英雄各自索敌 |
| 3 | 「**本質上還是自動打怪系遊戲的延伸**，沒能創造太多核心體驗上的差別」 | ✅ 对 |
| 4 | 「**內容變化不大**……從前面到後面都是做一樣的事情」 | ✅ 4 窝→BOSS，全部相同 |
| 5 | 「**布陣的必要以及彈性也相對有限**」 | ✅ 队形纵深 52px **<** 敌人攻击半径 60px，站位在数学上无效 |

**五条差评，五条命中。**

这不是"我们还没做好"，这是**这个骨架在单人体量下的天然上限**。而解掉这五条需要的药（短 CD 群伤、无限复活、海量面板、卡关付费）我们一味都没有。

### 证据 3：你自己说的口味指向「甲」，不是「丙」

《最终方向推荐》原文：

> **你爱玩**（软，但最容易被忽略）：**你自己回答过：土豆兄弟 / 吸血鬼幸存者式肉鸽**

这两个信号的分量完全不同，别混：

| 信号 | 你说了什么 | 含义 | 可信度 |
|---|---|---|---|
| **正向偏好** | 「我玩土豆兄弟/幸存者」 | 我想玩这个 | **高**（自述口味） |
| **否定信号** | 「我要百炼英雄那样」 | 现在这个不像 | **低**（只否定，未指定终点） |

你说"我要百炼英雄那样"，最可能的不满其实是**"环绕转圈很怪、没有队伍感"**。这个不满，用**列队跟随**一条就能解掉 —— 不需要把骨架整个换成佣兵团like。

## 三、落地性对比（这一栏很反直觉）

| 维度 | **甲（原点：割草+宠物状态）** | **丙（现在：佣兵团like）** |
|---|---|---|
| 核心循环 | 20 波怪潮 + 自动开火 + 三选一升级 | 编队 + 清窝 + BOSS + **局外养成** |
| 已有 3207 行代码复用 | **渲染 490 / 敌人 AI 433 / 弹道 119 / 池 30 / 结算 123 全用** | 同左 |
| 要改的 | `EncounterManager`（清窝→波次）、`BattleDirector`（通关→20 波）、`HeroSquad`（只改索敌/喂食）≈ **300–400 行** | **新增 4–5 个系统**：编队 UI / 技能系统 / 多关卡 / 局外养成 / 装备 |
| 爽感从哪来 | 怪潮压力 + 局内成长（Brotato 已验证） | 数值面板（要海量养成内容） |
| 单人 8–10 周出可玩 demo | **能** | **不能**（上一轮审计已量化） |
| 单人完整版周期 | 4–6 个月 | **12 个月+** |
| Steam 先例 | Brotato：1 人 / Godot / 轻美术 / 千万套 | 未搜到（都是手游/小游戏） |

**反直觉但重要：改回甲，比继续做丙更省。**
因为丙的"队伍感"必须靠养成深度去撑，而养成深度是这类项目最贵的那部分。

## 四、推荐方案：甲做主干，丙只做表现层

| 层 | 取谁 | 理由 |
|---|---|---|
| **战斗骨架** | **甲**：怪潮波次 + 自动开火 + 三选一升级 | 你的真爱；有 Brotato 完整先例；单人最省 |
| **队伍表现** | **丙**：列队跟随（`HERO_SLOTS` / `Formation` 原样保留） | 环绕很怪；代码已写完，一行不扔 |
| **敌人模型** | **乙的 CR-008**：半径制攻击/施法（保留） | 这是乙唯一的真遗产 —— 它让"走位"第一次有了意义 |
| **主动性** | **保留"窝"作为可选战术点** | 场上持续有怪，同时地上有高密度"窝"，引怪还是踩窝由玩家选 |
| **宠物状态** | **甲的喂食战术**（战斗中喂，短时 ×1.5） | 这是全部差异点，丢了就只剩"又一个割草" |
| **家园 / 关系网 / 半饿矩阵** | **砍到 M2 之后** | 落地性审计已量化：单人做不完 |

一句话产品定义：

> **你带着一支小队在怪潮里跑位，捡经验变强，还要在正确的时机喂饱它们——饿着打更狠，但会掉队。**

这个组合目前**没有人做过**（幸存者like 有队伍但没有状态；佣兵团like 有队伍但没局内成长也没状态），且单人 8–10 周能做出可玩 demo。

## 六、如果你仍然要走丙，唯一的活法

诚实说清楚，不是不能走，是代价在别处：

| 必须做 | 代价 |
|---|---|
| 给英雄 HP + 倒地规则 | **违反红线②「无失败惩罚」**，需要先改红线 |
| 队形摊开到 120px+（`纵深 > 攻击半径 60 + 双方碰撞 27`） | 4 个单位在 960px 屏里从"小队"变成"散珠"，和"列队紧致感"直接冲突 |
| 加打断 / 减速 / 集火等可操作技能 | 唯一纯加法的方向，+80~150 行 |
| 每窝 10 → 20~30 只（把 5.2 秒拉到 20 秒+） | 纯加法，但同屏数量上去后 DrawCall 与 GC 要重测 |
| 局外养成（英雄等级/装备/天赋） | **这才是真正的坑**：没有它，丙的爽感不成立；有它，单人做不完 |

**做完之后它也不是"百炼英雄"，而是"一个单人的、小体量的、战术走位游戏"。** 如果是这个定位，那不如直接做甲——甲更便宜，而且差异点更硬。
