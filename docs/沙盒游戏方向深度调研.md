# 沙盒游戏方向深度调研（2026-10-14）

> 用户约束：单人 / 轻美术（Q萌偏好）/ 会 Godot / 想做"宠物 + 趣味性玩法"且要有创新性
> 前置结论（见本工作区前 9 份报告）：宠物塔防（手持萌物炮·主动瞄准）是已验证白空间，但美术权重高、易"很快就腻"；桌面伴侣口碑好但卖不动。本篇评估"沙盒"能否同时满足轻美术 + 宠物 + 单人可落地。

## 一句话结论

**沙盒是迄今所有候选方向里，唯一让"轻美术"从短板变成资产的品类。** 自动化/生物沙盒的核心价值在"系统涌现"而非"画面表现"——一个画面粗糙到被媒体形容"五官凑不出10个像素点"的单人游戏，靠玩法深度卖到 12 万套、峰值 1.25 万并发。但这条路要求另一种能力（系统设计与数值平衡），且极易范围蔓延，风险结构和宠物塔防完全不同。

三条关键发现：
1. **单人 + 轻美术在沙盒里能爆**（Sandustry 1人/12万套/97.5%；异形工厂系列 1人/累计200万套）。
2. **"生物朋克 / 基因流水线"是 2026 明确上升浪**——把工厂里的"机器"换成"活物"，这恰好是用户"宠物兴趣"与"沙盒"的天然汇合点。
3. **"桌面独有生物沙盒"已有人跑通雏形**（Neofold：GPU 程序化生成、桌面伴侣+动物园+沙盒三标签合一），证明"宠物+沙盒+桌面"的融合不是空想。

## 一、市场验证：单人 + 轻美术 在沙盒里能爆

| 作品 | 开发者 | 美术 | 成绩 | 关键点 |
|---|---|---|---|---|
| **Sandustry**（金沙工业） | Erik Lantto（**单人**） | 2D 像素颗粒、粗糙色块，"功能性像素" | 97.5% 好评 / 评测 1.8K–3.2K / 峰值并发 **12,500** / 销量 **12万套**（GameLook）或 35.8K（VORYTHIC 模型，存疑） | Hooded Horse 发行；物理像素沙水蒸汽实时反应；"画面抽象"但玩法出挑 |

## 二、三个子方向

### A. 自动化 / 工厂沙盒（系统即玩法）
- 范式：挖矿 → 运输 → 加工 → 反应 → 产出，玩家搭"生产线"看它自己跑。
- 优势：美术权重极低；反馈环（"再建一条线"的掌控感）留存极高；18183 调研称"自动化"相关搜索同比 **+42%**、留存比传统生存高 **~35%**。
- 风险：Factorio 阴影（品类天花板已被定义）；**范围蔓延是头号杀手**（永远能加"一台机器"）；系统设计（数值平衡、反馈环）难度高。
- 单人可落地锚点：Sandustry 证明"物理像素 + 破坏性地形"即可差异化，不必复刻 Factorio。

### B. 治愈系生物收集沙盒（造景 + 萌物）
- 范式：无计时/无失败，自由布置家园、养萌物、看它长大。
- 样本：**Shroomy Garden**（蘑菇人 Shroomies + 主题公园建造）、**Verde**（Seedlets 植物小生物 + 村庄建造，Assemble 发行 $9.99）、**Cozyrama**（$4.99 微缩景观 + 萌动物）、**OddFauna**（手捏黏土生物 + 在巨兽背上建家）。
- 优势：与用户 Q萌 偏好 100% 吻合；美术轻量（像素/黏土感均可）；情绪价值高、差评少。
- 风险：品类偏"佛系"，销量天花板通常低于自动化（多为数千~数万份）；容易沦为"布置完就无事可做"。

### C. 生物 / 动物园 / 水族箱沙盒（养 = 玩）
- 范式：建栖息地、孵化/收集物种、维持生态（水质/温度/食物链）。
- 样本：**Temporarium**（单人 3 年、春池生物水族箱、治愈向）、**Strange Zoo**（动物园经营 + 龙卷风/UFO 混乱事件，100% 但仅 11 评测）、**Ultraquarium**（鱼类编辑器 + 创意模式）、**Dragon Spot**（建龙岛、居民养龅牙宠物，$5.99）。
- 优势：直接承接用户"宠物"主诉求；"养"本身就是系统（生态模拟），天然耐玩。
- 风险：重模拟易变复杂（Temporarium 作者养二十年 Triops 才做出来）；纯收集易"集齐即弃"。

## 三、2026 上升浪：生物朋克 / 基因流水线（关键差异点）

18183 行业稿明确指出自动化沙盒的**最新分化方向**之一是：

> **生物朋克与基因流水线**——"与其建造钢铁机器，不如培养'生物机器'，通过修改生物基因让特殊的'工蜂'或'载具'自动搬运物资。你的工厂是一个活着的系统，需要喂食、维护生态环境，否则生产线会'生病'甚至反噬。"

**这就是用户的宠物兴趣与沙盒的完美汇合点**：把"传送带上的箱子"换成"你养的生物"，自动化对象从机械变成活物。它同时满足：
- 轻美术（生物造型比工业机械更易做 Q萌）；
- 宠物主诉求（你养的"工蜂"就是宠物）；
- 系统深度（生态/基因/食物链 = 无穷的策略层）；
- 创新要求（相对 MOCHI-O 式"手持炮"是彻底不同的切入点）。

## 四、沙盒 vs 宠物塔防：同一人的两条路怎么选

| 维度 | 宠物塔防（手持萌物炮） | 沙盒（自动化/生物） |
|---|---|---|
| 美术权重 | **高**（Q萌是卖点本身） | **低**（系统是卖点，轻美术是资产） |
| 核心能力 | 动作手感 / 关卡 / 数值 | **系统设计 / 数值平衡 / 涌现乐趣** |
| 单人可落地性 | 中（MOCHI-O ~6.8K 份锚点） | **高**（Sandustry 12万 / 异形工厂 200万） |
| 白空间 | 中（仅 MOCHI-O 标杆） | 中高（自动化拥挤但"生物自动化"空白） |
| 头号风险 | 很快就腻（需叠深度层） | **范围蔓延 / 系统过复杂** |
| 用户技能匹配 | 需要美术+动作设计 | **更吃开发者系统思维（Godot 友好）** |

**判断**：若用户擅长且享受"搭系统、调数值、看涌现"，沙盒上限显著更高、且轻美术不再是负担；若用户更想做"一只亲密伙伴的手感体验"，宠物塔防更聚焦、scope 更可控。

## 五、融合机会：生物自动化沙盒 × 桌面伴侣 × 程序化

把前面所有报告串起来的最可能"又轻美术、又宠物、又创新、又单人可落地"的组合：

> **你养/培育的生物，既是宠物也是工厂工人。它们在你的真实桌面上生活（桌面伴侣层），你真实的活动（专注/摸鱼/开了什么软件）影响它们的状态；而在战斗/生产层，这些生物被编入"基因流水线"自动搬运、反应、产出——养成直接变成产能。**

支撑证据：
- **Neofold**（ChromaTactic，$3.99，93% 好评）：标签同时是 `Creature Collector` + `Desktop Companion` + `Idler` + `Zoo` + `Sandbox` + `Procedural Generation`——"每个宠物都是 GPU 实时生成、只存在于你桌面的独有生物"。这证明"桌面独有生物 + 收集 + 沙盒"的融合已被市场接纳。
- 桌面伴侣层技术（Godot 透明窗口/置顶/穿透）前已证实可行。
- 程序化装配（前《深度架构》L2）在此可直接复用：生物 = 头/身/器官/基因拼装，万级内容、美术零边际成本。

**差异化的护城河**：现有生物沙盒（Temporarium/Strange Zoo）几乎都是"被动养"，没有"生物即生产力 + 桌面入侵 + 程序化生成"三者的叠加；Neofold 有桌面+程序化但缺"自动化生产"维度。三者拧合即空白。

## 六、风险清单（沙盒专属）

1. **Factorio 阴影**：品类被定义，后来者易被比"不如 Factorio"。规避：用"生物/桌面/程序化"做差异，不正面拼工业深度。
2. **范围蔓延**：沙盒的诱惑是无限加内容。规避：MVP 只做"一种生物 × 一条生产线 × 一个反馈环"，验证爽点后再扩。
3. **系统设计门槛**：反馈环设计错 = 无聊或崩坏。规避：先抄成熟模型（资源→加工→产出→解锁），把创新放在"生物化"而非"重造系统"。
4. **性能**：海量实体模拟是 Godot 硬伤（前《塔防射击》已述：裸跑 50 敌掉帧）。规避：godot-jolt + 对象池 + RenderingServer 直绘 + 空间分区，同屏 500–600 实体 @165FPS 可达。
5. **行为检测红线**（若含桌面层）：只统计不记录 / 默认关闭+明示 / 本地处理 / 商店页主动解释，避免 Character House 的 `keylogger` 差评（见《可落地性》报告）。

## 七、数据可信度分级

- **高**：Sandustry 好评率 97.5% / 峰值并发 12,500（DLCompare、Steam 一手）、Hooded Horse 发行事实、Project P.I.T.T. 11.5万愿望单（媒体交叉）、各作品 Steam 标签与价格。
- **中**：Sandustry 销量（GameLook 12万 vs VORYTHIC 35.8K 冲突，取"数万~十万+"量级）、异形工厂 200万累计（媒体转引）、Neofold 15 评测/93%（样本小）、18183 搜索 +42% 与留存 +35%（国内行业稿，方法未披露，存疑但方向合理）。
- **存疑**：各作品好评率随时间波动；中文 SEO 站点（蒸汽雷达/游戏大观）措辞带推广腔，统计数字不单独采信；"生物朋克是 2026 上升浪"为单篇行业稿判断，作趋势参考非定论。

## 八、建议的下一步（待用户决策）

1. 若认可沙盒方向：先做 **MVP = 一种生物 × 一条基因生产线 × 一个反馈环**（纯自动化原型，不碰桌面层），验证"养 = 产能"的爽点。
2. 若想保留宠物塔防手感：可在沙盒里加"手持萌物"作为"手动干预工具"（手动 vs 自动的张力），而非主战斗框架。
3. 若想最大化差异化：直接做"生物自动化沙盒 + 桌面伴侣 + 程序化"三合一（见第五节），这是当前所有候选里理论契合度最高的形态。

> 注：本方向与前《Q萌生物×塔防射击_深度调研》《手持萌物炮_深度架构分析》互补而非替代——沙盒解决"轻美术反而有利"与"上限更高"，塔防解决"手感聚焦、scope 可控"。最终可二选一，或把塔防作为沙盒内的一个子系统。
